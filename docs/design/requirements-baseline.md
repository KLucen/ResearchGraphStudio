## 2. 开发方向

ResearchGraph Studio 是面向科研人员的**本地证据推理与知识演化桌面工作台**。产品价值是让研究者核查、比较和修订跨论文主张；研究价值集中在实验条件约束的关系推理、人机协同审核和增量影响分析。

正式研究题目沿用原文建议：《基于证据约束推理与增量知识演化的科研知识图谱系统设计与实现》。创新性须通过相关工作分析与对照实验验证。

v0.1 闭环：**导入至少 5 篇相关论文 → 抽取主张与证据 → 比较实验条件 → 生成候选关系 → 人工确认 → 图谱查看 → 保存项目 → 导出研究报告**。

v1.0 在该闭环之上增加 Zotero 默认只读入口、授权个人笔记回流、依赖驱动增量演化、受控 Wiki 发布、Query/Lint 与实验中心；工程容量目标为约 10–30 篇英文计算机科学论文。首发目标 Windows 10/11 x64，其他平台后续验证。Phase 0–6 取代旧四阶段，约 12–19 周为新范围估算；计划版本 v0.4 不表示产品版本已完成。

## 5. 范围与剩余准备

v0.1 必须包含论文项目、文本 PDF 解析、证据锚定、结构化主张与条件、五类候选关系、人工审核、图谱、持久化和 Markdown/JSON 报告。数据由引擎统一写入；审核事件从第一版就保留，为后续演化提供历史。

v1.0 增加增量影响分析、版本差异/回放、Zotero 只读适配、授权笔记回流、受控 Wiki Ingest/Query/Lint、批量实验与安装发布完善。文件级导入/导出不是对任意个人笔记的双向自动同步。自动论文搜索、全学科知识库、完全自主科研 Agent、自动判定新颖假设、复杂 OCR/图表自动理解和多人协作不进入当前交付范围。复杂 PDF 应显示限制，并提供原文/人工校正路径。

Rust/MSVC 构建工具已补齐；尚需在对应阶段补齐：干净 Windows 安装验证、首批可用样本文献、模型供应商与可用配置、实验标注者和用户实验安排。这些是可分阶段处理的依赖，不影响先开展离线骨架和证据流程。
