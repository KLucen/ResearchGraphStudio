# ADR 0005：模型能力、持久化批次恢复与实时点图

日期：2026-11-02。状态：采用。继承 [ADR 0004](0004-v3-projection-and-unified-extraction.md)，Alembic head 仍为 0009。

用户实际任务按旧规则产生 48 批，第 2 批输出截断。任务排队时冻结的上限为 8192；之后在设置页填写 65536 不改变旧快照。旧章节/页边界强制拆批导致调用数偏多，卡片拖动与静态布局也不符合新版探索体验。

## 决定

1. 移除手工最大输出设置。服务器只读取配置端点 `/models` 中精确模型条目的可信数值能力，客户端不能写入能力。能力未知时省略输出参数，使用供应商默认并明确标识；不根据别名猜最大值。历史快照保留但不再将手工限制发给模型。上下文已知时扣除输入预算和余量。
2. 新任务合并相邻段落，默认目标 12000 字符，完整 EvidenceSpan 不截断。旧任务按原规划恢复；计划、来源哈希、模型/Prompt/Schema 签名保存在 Job payload。已提交批次永久跳过；失败的输出/上下文过长批次可二分，最多三层，单个证据过大明确失败。拆分与提交共用 KnowledgeOperation 幂等账本，不增加数据库表。
3. 网络、超时、429、5xx 最多三次退避尝试。无效 Schema、陌生证据、鉴权等不会盲目重复调用。记录每次尝试的实际限制、供应商用量和失败原因，保存截断原始输出；未返回用量或费用不能宣称为零。
4. React Flow 只显示点和低饱和半透明边；有界力模拟在拖动时继续作用于邻居。双击切换固定，详情中的按钮聚焦邻域。RAF 更新局部位置，松手/冷却后保存；稳定后停止；从按下位置跟踪快速拖动，但仅坐标变化时持久化，减少动态效果时收敛后直接展示。布局冲突重载替换画布与本机草稿，知识 revision 不变。
5. 正常设置、抽取、补译、推理入口只选真实全局模型。旧抽取和 Mock 仅显式测试/历史兼容；不删历史知识。正常视图排除未经人工编辑的 Mock 来源节点，人工接受、修订或无模型来源的记录继续展示。父论文作为有界上下文节点补入分页，连接真实 REPORTS 来源边，不据此推断科学关系。

## 影响与验证

保留旧 ID、英文、证据、模型输出、人工审核和原始 PDF；不迁移或覆盖用户库。数据库 Schema 无变化。真实验收在一致性副本完成，安装包不包含数据库或凭据。

代价是未公布能力的供应商仍可能截断；拆分后总批次可增加。内部字符预算不是精确 tokenizer；巨型单 span、万节点性能和全文科学准确率不在已验证结论内。测试与真实调用范围见 [优化验收](../archive/reports/refinement-verification-20261102.md)。
