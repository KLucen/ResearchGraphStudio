# ADR0052：可续接的论文分页解析、受限格式修复与边界复核

日期：2026-11-18（Asia/Shanghai）。状态：已实施；真实供应商兼容和论文识别质量待验收。

## 需求与范围

用户明确要求继续开发分页解析、检查点、跨页续接和一次格式修复，覆盖此前“只分析方案、不实施”的该项阶段边界。原整篇请求曾在返回后因契约不符失败；延长等待时间不能解决返回结构错误。新流程降低单请求规模，并把失败与续接范围限制到批次，不承诺整篇耗时一定缩短。

本决策覆盖模型文档解析；概览、全文精读和中文翻译仍是用户另外选择的后处理任务。本地解析保持可选，模型失败不自动回退。旧任务计划没有显式开启 document_batching 时继续原整篇路径，旧快照、历史结果和既有阅读状态不重写。先前独立超时与页面图片能力见 [ADR0051](0051-document-timeouts-and-visual-pdf-input.md)。

## 批次与新契约

- 新 PDF/后续模型重新解析计划默认 document_batching=true、pages_per_batch=5，公开设置范围2–8页，包含相邻前1页共享上下文，顺序发送。规划器可以因已知上下文、输出和实际图片容量缩小批次，不会扩大用户选择。原始 PDF 最大50MiB、2048页；这些是软件资源上限，不是供应商支持承诺。
- 默认例子：第一批核心与发送页为1–5；第二批核心页6–9、发送页5–9。共享页只辅助理解，不重复发布为核心材料。PDF只作页复制，图片路线只渲染页面，不调用本地正文/OCR/公式/表格抽取。模型和端点仍必须实际支持所选 chat_file 或 chat_images。
- 输出版本 document-batch-1 在每个片段保留原始 page_start/page_end、continues_before/continues_after、章节及材料字段；批次有核心页范围和 unavailable_pages。核心每页必须出现在片段来源范围或 unavailable_pages，后者不能重复、越界或与已覆盖页重叠，且必须有警告。这个检查证明页码声明完整，不证明该页文字已经科学准确地识别。
- 批次严格拒绝未知字段、重复JSON键、非有限数、错误类型、越界页码、乱序及不满足材料要求的段落/公式/表格。脱敏错误仅保留已知字段组成的路径和稳定错误码，不包含未知模型键、输入值或异常正文。是否采用原生受约束输出仍依已有精确端点能力策略；兼容JSON模式不冒充严格Schema。

## 检查点、版本与请求账本

运行表 llm_document_batch_runs 绑定导入会话、任务、源文件版本、冻结模型快照、契约版本和实际页范围；llm_document_batches 分别保存抽取与边界检查点。源版本使用 size、mtime_ns、ctime_ns、device、inode和页数，不把SHA-256作为解析前置条件。该元数据检查不是字节相等证明，保留元信息的原地修改可能无法识别；用户有意换源应创建新解析。

请求发送槽位在POST前持久化。每批通过校验后立即以 validated 保存结构化结果，续接前再次核对源版本、任务/会话、冻结快照、协议和完整页范围；已成功批次重新验证后复用，不重新发送。失败原始响应不持久化，不写入日志；失败只保存状态、安全错误、请求计数和供应商实际用量。当前原始失败响应仅在本次进程内用于已授权的修复，进程退出后不能无请求地恢复它。

进程中断、网络失败或发送结果不确定时不自动重发。用户显式继续才授权未完成批次的新执行槽；每批最多3次显式执行，已有格式修复槽仍最多1次。继续会增加显示的请求预算并可能再次收费，不能把不确定请求视为未计费。打开页面、轮询或重复GET不推进任务。

## 受限格式修复

allow_format_repair默认false，由独立复选框授权。每个抽取批次最多额外1次API请求，且只发送该批响应文本、同版Schema与脱敏错误，不重新上传PDF、图片或源路径。第二次响应仍须全部校验；程序逐片段保守核对文字、公式、表格、页码、章节归属、顺序与续接属性，无法证明仅作格式修正时拒绝保存，不猜补内容。原始JSON损坏到无法核对材料时，也不能以模型声称“修好了”绕过保护。

这不是科学校对或补全工具，不更正论文数字、公式语义、翻译或结论，不通过无限重试掩盖失败。再次不合格即停止并保留安全诊断。没有授权时不产生该请求。

## 相邻边界复核与合并

只检查上一核心批末片段和下一核心批首片段的续接标记。有续接信号且allow_boundary_review=true时，最多为该边界额外请求1次，发送原始相邻2页及两个已校验片段。模型只返回 document-boundary-1 的 merge / separate / uncertain、受限分隔符与理由枚举，不重写材料正文。

程序仅在merge且材料类别、章节标题和层级等条件兼容时确定性拼接，并保留原始页范围和来源片段；状态从严合并，不能因续接判断把不确定材料升级为可靠。表格仅支持对象只含 columns/rows、两侧列定义相同且 rows 均为列表的简单结构，按原顺序追加行；模型明确判定重复表头且右首行与列名精确相等时，程序才从结构化rows移除该重复表头，原始表格文本继续保留。复杂合并单元格、列变化、无法确认或长度超限保持原片段并至少标 needs_review，原 unavailable/failed 状态保持，不冒充全文语义无缝合并。

未检测到续接标记不调用边界模型；这意味着漏标可能仍留下断句。关闭边界授权时不发送该类请求，有续接信号则保留不确定提示。所有批次均无可读材料时不发布空的成功解析；有unavailable_pages的结果保留明确警告，不能标为全文无缺口。

## 预算、进度与时限

若规划得到B个抽取批次，初始请求预算为B，加已授权边界检查最多B−1次，再加已授权格式修复最多B次。边界无需模型时不消耗请求，概览/精读/翻译另计。批次数确定前界面显示此公式；之后显示当前/总批次、原始页范围、已校验数、已发送/预算、修复次数和边界完成数。字段错误只显示安全路径/码，不展示任意响应正文，不编造模型内部百分比。

默认600秒响应等待与1800秒总时限均针对单次HTTP请求，不是整篇SLA。批次准备也使用默认1800秒的可配置准备deadline，在线程执行并在读入、逐页预检/渲染和规划循环间检查取消及截止时间。单次原生页渲染不能中途打断，页像素资源仍有界。整篇包含多个请求，耗时和费用可能高于一次请求；不保证真实供应商不再超时。

## 迁移与数据边界

Alembic head新增为lite0013，加性创建批次运行和检查点表，升级前自动备份，旧阅读/模型行不重建。清除旧本地解析/缓存保留模型批次及个人笔记；整篇删除时按关联删除批次和运行，引用源PDF保留，托管副本仍遵循受控删除规则。不得用正式用户数据库作迁移或失败实验。

## 验证与已知限制

实际专项与未完成项见[本轮验证](../document-batches-verification-20261118.md)。本轮未调用真实模型、未访问正式用户数据库/私人PDF/凭据，未Commit/Push。模拟Provider、Edge真实React渲染和隔离存储测试不能代替真实供应商能力、论文章节/公式/表格质量、用户原生GUI或干净机验收。
