# ADR 0020：带原文核对的贡献选择与证据上下文底线

日期：2026-11-03（Asia/Shanghai）。状态：R5质量修复；实际结果见[收尾验收](../archive/reports/r5-final-verification-20261103.md)。数据库与领域版本不变，不进入P4/P5。

## 真实验收发现

隔离真实论文中出现了合法EvidenceSpan ID、hash、offset和quote，却不受该quote语义支持的候选；另有上标在纯文本中展平导致数值误读。原始PDF、结构化行/span字号及坐标仍保存。锚点合法只证明来源身份和引用位置，不能证明候选意思被原文支持。

P13 v1只有候选与支撑的文字及证据短编号，没有原文文本，无法独立核对支持关系。只验证Schema或单元路径会错过这一问题。

## 新选择协议

新增独立的 `P13_reading_ranking_v2`。新finish计划显式冻结 `ranking_prompt`，签名按实际Prompt名称与内容计算；旧计划缺该字段时继续v1，原文件、输入、缓存及签名不改。v2返回仍使用已有贡献建议DTO，不增加人工审核或让模型改写候选。

v2输入提供论文来源信息、本次完整引用原文、根和支撑已有疑点，并加入精确映射的数字排版风险材料。模型逐项核对结论及必要支撑的语义、归属、数值与条件；不受支持或上下文不足时用 `needs_context / insufficient_support`，不能仅凭合法编号建议核心。同范围、条件和归属的等价结论优先保留一个代表；不同条件不能强并。建议仍是模型辅助判断，不是真实性证明。

新输入冻结并在响应/缓存终验时复核；来源、疑点或排版上下文变化不得通过额外付费绕过。旧任务不悄悄切到v2；使用新规则时创建新构建，候选与历史原样保留。

## 程序硬门槛与质量表达

Claim的全部直接证据若仅为空白、单字符、数值或明确数学标记碎片，就缺少可解释原文上下文，不进入默认或临时核心；显示偏好不能绕过。该规则不按字符预算截断文档，不删除候选，也不强制所有科学证据必须是自然语言：公式加说明段落、中文短句与英文短语可通过。多字母缩写等不明确情况保守放行，不能把这一启发式当语义蕴含检测。

不合格的历史缓存不能再次发布，已有图谱与原选择记录保持。`needs_context`、明确 `insufficient_support` 或碎片依据对应证据充分性为 `insufficient`；已有支撑疑点汇总为单元caveats，使其至少为 `limited`，不能因根自身没有疑点就显示充分。

## 数字排版风险

只读利用同文献版本DocumentParse与Chunk/EvidenceSpan的精确映射；检查原line.spans中数字相邻片段的字号与基线变化。仅将风险、原行和span的文字/字号/bbox作为程序上下文，不把展平文本自动改成指数、正式值或新证据。无结构、映射不一致与已检查无风险分别记录；不按页码猜对应块。

新P13遇到这种风险时不得将不可靠数值当确定支撑。复杂公式、版面与表格仍存在解析限制，无OCR或普适公式理解保证；原始材料和未选候选继续保留。

## 验收边界

分别检查新v2上下文与旧v1精确兼容、碎片门槛、支撑疑点、排版提示、来源变化与失败续接，以及真实候选中已知错误是否进入核心或支撑。Schema通过、15/15批次完成或模型自述不能替代独立对原文的质量核验。模型仍可能出错，未通过项须在报告中保留，不标R5全部结束。
