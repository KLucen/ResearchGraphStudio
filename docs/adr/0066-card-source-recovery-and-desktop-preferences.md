# ADR0066 · 论文卡片集引文恢复与桌面阅读偏好

日期 2026-11-21（Asia/Shanghai）。承接 [ADR0065](0065-evidence-grounded-paper-card-sets.md)。

## 已保留响应的来源校验

用户报告卡片集生成失败。只读核验确认该模型后处理 v5 响应完整，严格 JSON 和字段校验通过，当前来源指纹与冻结计划一致。27 张卡片共 110 条引文，其中 17 条在指定来源及其余冻结来源均没有精确匹配，影响 9 张卡片。故障发生在卡片引文校验阶段，已完成的 3 批 PDF 解析可继续用于阅读。

模型来源卡片可用显式本机恢复。恢复先验证原始响应合同和当前来源，整张排除含不可验证引用的卡片，再按普通发布规则复验保留卡片与来源。简要总览和覆盖说明根据恢复结果确定性生成。恢复保存在已有本机恢复记录中，界面明确标记部分恢复。原失败任务、原始响应与请求用量保留；读取、恢复均不发送模型请求。仍需完整重生成时，以用户再次明确授权为准。

新模型来源任务冻结 v6 合同。模型引用程序预先编号的原文摘录，程序从冻结材料恢复原句、重现位置及来源身份，新结果继续使用 `paper-card-set-2` 展示。非法引用仍拒绝普通发布。旧冻结 v5 请求继续按原精确引文合同解释。沿用现有表，数据库 head 为 `lite0018`。

## 任务记录、阅读与窗口行为

- 任务记录从冻结任务类型投影一个安全的阅读任务标签，分别显示卡片集、全文精读笔记、逐段中文翻译。阅读工作区只显示进行中的任务名称；请求计时、批次细项与历史失败留在任务记录的对应条目，原有必要的恢复操作仍可使用。
- 本机记住最近一次明确切换的本地/模型阅读来源。某篇论文只有一类解析时使用该来源，之后阅读两种来源均可用的论文时仍恢复所记偏好。重新解析时可以查看刚提交的解析类型，阅读偏好只在用户明确点击“查看”时保存。
- Windows 首次关闭主窗口时询问隐藏到任务栏托盘或退出主程序，取消时窗口保持打开。所选行为持久化，之后可在“设置与诊断 → 桌面窗口”切换。托盘操作可打开现有窗口或退出，后台引擎在托盘模式下继续运行。
