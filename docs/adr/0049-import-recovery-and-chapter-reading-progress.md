# ADR0049：导入失败恢复与全文精读章节进度

日期：2026-11-18（Asia/Shanghai）

状态：已实施；实际验证和安装交付以 [progress](../progress.md) 为准。

## 背景

用户安装后的反馈包括：删除论文被桌面宿主拒绝；Zotero 模型解析因 `DetachedInstanceError` 失败，但论文仍显示“解析中”；解析前标题显示为 Zotero 条目键；阅读状态和小节导读分散在独立入口，难以接续全文阅读。

## 决策

桌面 Host 精确放行单篇论文更新、删除和清理旧内容的管理路由，继续校验 UUID、HTTP 方法和查询参数。操作仍由引擎备份与来源文件路径边界保护。

Zotero 选择请求携带浏览得到的论文题名，排队时立即用于 Paper 标题；旧请求缺失题名时保留兼容后备值。模型 I/O 只使用数据库事务内复制的计划、来源和授权普通值，不在会话关闭后读取 ORM 属性。解析异常同步记录 Job、解析、计划项和导入会话；启动时对齐终态 Job 遗留的活动计划，不重新排队或调用模型。显式取消和重试同步相应状态。

模型 PDF 解析目前是单次非流式请求。任务和论文视图显示实际阶段：读取 Zotero 附件、准备模型、等待模型解析、校验结构、保存章节材料。等待期间明确说明要等待完整结果，不生成百分比或虚构章节完成数量。按章节批次的真实细粒度进度仍属于后续能力。

取消检查覆盖 Zotero 附件异步读取、PDF 字节异步读取和 HTTP 客户端准备，在真正 POST 前重新验证 Job 仍为 running。本地回调不进入模型 payload 或请求正文。取消/失败/中断发生在发送前时不外发，不改写已有终态；HTTP 已发出后不能撤回供应商处理，但取消后不发布结果。已授权联网的失败任务只通过用户明确点击“重试模型解析”重新排队，旧计划没有联网授权时要求重新导入。

正常精读入口直接显示全文；移除“小节导读 A01”和独立“理解状态与旧笔记”的切换入口，兼容存档和 API 继续保留。大章节下提供“未开始 / 阅读中 / 已读完”，目录显示已读状态并提供续读定位。阅读状态由用户显式标记，不由滚动或模型生成自动标成已读。

窄屏目录的续读目标保留固定工具栏下的滚动间距，保证聚焦章节标题完整可见；620px 和 390px 使用实际继续阅读点击验证，不通过人为截图滚动掩盖遮挡。

旧本地全文使用既有 Section 阅读状态，通过专用 PATCH 仅更新进度，保留原自评、疑问、失去关联的概念和来源基线。模型全文使用新的 `llm_chapter_reading_states`，以 `parse_id + chapter_ref` 唯一绑定；大章节按当前模型解析中的最小标题层级确定。新解析不继承旧解析的已读标记，历史记录保留；版本已变化或章节不属于当前解析时拒绝更新。

`lite0012` 仅加性增加章节进度表，升级前自动备份。不转换旧 Section、不重写模型转录、不清空笔记或 PDF。清理旧解析保留模型章节状态；删除整篇论文时在同一事务删除其状态，不影响其他论文。章节状态 API 和续读均为本地操作，不调用模型。

## 验证边界

隔离回归覆盖快照 Provider 分支、异常终态同步、旧失败任务恢复、阶段展示、Zotero 题名传递、阅读进度保存与重启、解析版本隔离、章节归属及管理删除。桌面回归使用真实 React 组件，Host 测试覆盖管理和章节状态的路由边界；Windows 安装测试使用匿名合成材料。真实 Provider 的 PDF 接收能力、章节/公式/表格科学质量和用户原生 GUI 体验分别记录，不以合成模型代替验收。
