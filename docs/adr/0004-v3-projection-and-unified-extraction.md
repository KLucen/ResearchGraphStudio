# ADR 0004：轻量投影、独立布局与统一抽取兼容层

后续调整：双击/拖动语义、模型预算和恢复规划已由 [ADR 0005](0005-model-capabilities-resume-force-graph.md)更新；下文保留原决策记录。

日期：2026-11-02。状态：核心实现已接入，实际验收见 [v3 验收](../v3-verification.md)；范围 M0–M6。

复用 Tauri、React Flow、FastAPI、SQLite/Alembic、KnowledgeStore 和现有全局 Provider。增加投影与统一抽取适配器，不建立第二套知识存储。

1. 0009 仅增加布局、显示元数据和来源结构边。保留原表、ID、原始 ModelRun、审核状态和知识事件；迁移自动备份，恢复使用备份而非破坏性降级。
2. 默认投影五类节点、短中文标签、英文回退与按需详情。来源状态和人工审核分离；通过证据校验的未审核节点可见，失效/驳回节点默认隐藏。
3. 布局使用单独版本与项目作用域，保存 x/y/pinned/viewport，不调用知识 revision。双击聚焦，拖动固定，显式按钮解锁。
4. 新 P02 统一章节抽取，保留嵌套实验/条件/Finding/Metric；严格 DTO 转换到现有领域对象后通过 KnowledgeStore 事务写入。旧 P01/P02 API 默认兼容，界面新入口显式选择 unified-v3。
5. 模型只引用本批短证据 ID。中文可缺失并标记待补译；原文和数字不得由显示字段覆盖。跨论文关系依旧经旧 P3 检查与审核；新来源结构边不得冒充科学推理边。
6. 任务状态、模型响应和提交记录分别持久化；批次提交与事件同事务。已提交批次不重复调用，收到但未提交的合法响应可恢复；超时、网络、限流与服务端错误有界退避，其余错误明确报告。
7. 复用现有轮询读取 graph revision 与任务状态；布局、筛选和详情不会触发模型。新增数据通过加性接口提供，原前端和旧 API 继续可用。

验证与限制以实际回归、隔离旧库和原生/真实模型验收记录为准，不因参考契约通过宣称真实模型完成。


补充边界：布局使用有界确定性力模拟，最多 70 次迭代，不新增 d3 依赖；保存节点不隐式移动，解除固定后由用户触发重新布局。待保存布局在本机浏览器存储暂存，页面切换后恢复；服务端版本冲突必须显式重新加载，避免覆盖另一窗口。

为保留关联完整性，本轮以整批为验证/提交边界，不把坏条目过滤后强行保存其余悬空依赖；已成功的其他批次仍保留。补译仅更改 KnowledgeDisplay，事件保存前后显示值，原 KnowledgeNode、accepted 状态、原 ModelRun 均不变；翻译标记 machine_unreviewed。

新运行 DTO 为 unified-v3.1，参考包 v3.0 与其并存：额外保留 Method 机制、嵌套 Experiment/Metric，Paper 由后端提供，来源 origin 仅 paper_author/citation_report，来源结构边强制证据。不把参考 SQL 直接执行，也不进行无意义文件目录重排。
