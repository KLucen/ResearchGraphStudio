# ADR0058 — 精读标记对应卡与就近批注布局

后续更正：用户反馈摘录卡重复且把实际分析挤到下方，相关显示/断点决定由[ADR0059](0059-reading-analysis-and-chapter-end-progress.md)覆盖；本页保留该次实现历史。

日期：2026-11-20（Asia/Shanghai）。状态：实施。验证见[本轮报告](../reading-annotations-verification-20261120.md)。承接[ADR0056](0056-unified-reading-from-parser-sources.md)与[ADR0057](0057-reading-output-and-workspace-recovery.md)。

## 问题

一段原文可以含多种精读高亮，界面右栏却只显示`paragraph_function`的“陈述论点”或“阅读批注”。它是整段功能，不能解释各处高亮类型；右栏固定顶边距也无法体现段内片段所在位置。当前本地与模型合同均只保存高亮的`type / quote_en / occurrence_index`以及整段的一份逻辑作用、核查提醒和阅读问题，没有逐高亮的独立解释文本。

## 决策

1. 本地与模型入口继续共用`ReadingParagraphCard`。每条合法高亮显示“段号.标记号”、类型名称和精确原文摘录；编号按原文出现位置排序，不按类型优先级排序。卡片不将整段说明重复冒充片段专属解释。
2. 原文保留全部文字和空白。编号用CSS生成，既有高亮颜色优先级不变；另保留每条高亮的原始索引和精确范围，相邻同色项不合并身份，重叠片段保留全部对应卡，重复原文仍按`occurrence_index`定位。
3. 桌面阅读区按实际可用宽度布局。卡片在同一个段落行容器中，以高亮首行相对批注栏的位置计算间距；同一行或密集标记按原文顺序向下避让，不重叠、不覆盖下一段。整段批注明确标注段号和整段范围，靠近该段译文显示；空间不足时同样顺延。
4. 点击原文标记聚焦对应卡，卡片“定位原文”反向聚焦原文；Enter和Space可操作。重叠标记的读屏描述列出全部编号，卡片分别保留定位入口。当前原文或分析改变后清除旧选中状态。这些交互不触发问答、图谱写入或模型生成。
5. 正文、来源元数据、批注卡尺寸以及字体加载变化都触发重新测量；只在组件内维护布局，不保存屏幕坐标、不监听每次滚动。卸载时取消RAF并移除观察与监听。窄于760px的实际阅读区切为段内单栏，保留编号、类型、摘录与双向定位；列标题按同一内容宽度隐藏。
6. 五色标记和图例样式由共享样式文件直接导入，独立组件无需依赖父页加载历史精读样式。

## 范围

这轮是已有结果的显示与交互调整，无数据库迁移、Prompt或模型响应合同变更。已有合法精读可直接重新读取；无须重新生成论文内容。`lite0015`及历史raw、失败/部分恢复记录继续保持。密集高亮在物理空间不足时会增加段落高度；窄屏按段落堆叠，不承诺每张卡与片段严格同高。

测试仅用合成可分发材料；正式库、私人PDF和凭据未读取，真实模型请求0。用户安装版原生WebView与真实论文阅读体验另行验收，不以浏览器截图代替。
