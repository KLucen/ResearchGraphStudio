# ADR0065：论文阅读工作区改用逐条有据的分类卡片集

日期：2026-11-21（Asia/Shanghai）。状态：已实施，验证与交付见[本轮报告](../paper-card-set-verification-20261121.md)。

用户明确要求取消论文概览中的单篇 LightGraph，不保留旧概览展示；研究内容知识库继续保留独立来源图谱与跨论文联系。新版概览以详细知识卡片为主，并提供文章总览和卡片集介绍。本决策覆盖 ADR0033/0056 中单篇概览联合生成 PaperCard + LightGraph 的新任务行为；不改写历史冻结任务或知识库历史版本。

## 内容合同

新领域版本为 `paper-card-set-2`，Prompt 为 `paper-card-set-extract-1`。一份模型输出包含文章总览 `article_overview_zh`、总览所据卡片 `overview_card_ids`、卡片集介绍 `card_set_intro_zh`、覆盖缺口 `coverage_notes` 和分类 `cards`。分类包括研究问题、核心贡献、架构/算法、数据/实验设置、评估、关键概念、主要结果、优点、不足和作者自述局限。不同贡献与结果可以分卡；没有固定类别数量，未发现内容须说明缺口，不能为凑齐模板编造。

每张卡片包括中英文标题、中文详解和阅读导引，以及至少一条精确原文依据。`AUTHOR` 表示作者明确表述的转述，`ANALYSIS` 表示模型基于证据的分析；优点/不足强制后者，作者自述局限强制前者。`quote_en` 是传输字段名，实际保留原语言，界面不把非英语原文冒称英文。辅助中文译文可缺失，不能替代权威原文。引文匹配、引用合法与科学含义正确分别表述；结果始终记录 `semantic_accuracy=unverified`。

JSON Schema 由实际严格 DTO 导出。拒绝重复 JSON 键、非有限数、额外字段、空白必需文本、重复卡片编号和重复证据；总览引用须属于本集。模型只填写短编号和语义，不产生正式 ID、页码、位置或图谱。程序从完整来源中检查原文与重现次数，生成稳定 ID 和真实位置。

## 来源与生命周期

两种解析共享 `knowledge_sources` 的完整已存材料读取，排除参考文献，不重复读取/上传 PDF、不静默截断。知识卡片与知识库使用独立输出合同、任务、版本和发布操作；卡片生成不会自动触发知识库建模或跨论文分析。

本地证据绑定阅读单元、章节和可靠页码；只有原始片段可以按顺序逐字重建完整阅读单元时才给出原始块偏移，否则明确降为阅读单元粒度。模型证据绑定真实 segment 与 locator；缺页码保留 null，不从章节序号猜页码。表格/公式仍保留解析质量限制，不从损坏版面推断科学含义。

新本地任务冻结合同、配置和来源清单，发送前、发布前和缓存/读取时重验。新模型后处理计划显式使用 `overview_contract_version=5`，冻结完整来源指纹、Prompt 与 Schema，发送后及发布前重验。旧计划缺字段或版本 1–4 沿用原执行，不根据模型返回的 schema 静默升级。已发任务持久记账，失败/取消/重启不会自动重发，退出协程专门保存已有 partial/usage 后重抛取消。确定性请求预检放在发送槽前；metadata后发现的确定未发生成请求保留槽并明确标 not_sent，聚合不冒充生成调用，未知发送仍保守保留。失败保留 raw 和实际用量；用户明确重新生成才可新建请求。

复用现有概览 JSON 表，不增加数据库迁移，head 保持 `lite0018`。新 GET 仅返回新版卡片，不回退旧概览。旧数据不迁移、不继续可见，但保留原始任务/账本和个人理解历史，避免破坏知识库已有独立快照。旧概念理解如失去当前有效卡片关联，标记 `NEEDS_RELINK`，不误绑新卡。本地精读历史字段可引用经过验证的关键概念卡；这不生成隐藏图谱或科学关系。

知识库 legacy 概览收藏仅选择 `paper_overview_graph.v1`，不能误选新卡片；已有知识库图谱、来源建模和联系汇报保持各自合同。新卡片不支持旧布局 API。共享 ForceGraph 继续服务独立知识库。

## 界面与本机管理

概览展示文章总览、卡片介绍与分类卡片。支持分类筛选、搜索、总览引用定位、展开原文/辅助译文，以及本地章节跳转。模型稿显示真实章节/片段定位及缺页说明。收藏、已读、隐藏/恢复和个人备注按来源、论文、解析版本与卡片结果版本隔离保存于本机浏览器存储，不改模型正文或知识库事实；保存失败必须明确反馈。

旧卡片图、画布布局和概念编辑面板从论文概览移除。打开、筛选、管理和重新读取不会调用模型。新生成需明确授权发送论文内容。真实 Provider、论文语义、译文准确性与用户日常原生体验仍需用户重新生成后验收，合成回归不替代这些验收。
