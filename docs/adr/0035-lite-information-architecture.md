# ADR 0035：Lite 项目的三层信息架构

日期：2026-11-10

状态：Accepted

2026-11-11 增量：用户新增版式翻译需求，按 [ADR0036](0036-optional-pdf-translation-bridge.md) 将右侧阅读工作区扩展为论文概览、章节精读、论文问答和文献翻译四个板块，原三层导航分工保持。

## 背景

Lite 当前同时在项目页面中展示论文导入、任务记录和项目文献。三者分别属于项目动作、系统活动和论文阅读内容，放在同一组可折叠区会让用户在选中论文前后都面对大量无关内容，也会削弱左侧项目树作为文献定位入口的作用。

## 决策

Lite 使用三层信息架构：

1. **左侧项目树**负责项目和论文定位。研究项目旁保留新建按钮；选中的项目提供导入论文动作；项目展开后直接列出论文，点击论文进入右侧阅读工作区。
2. **一级导航**只保留研究项目、任务记录和设置与诊断。任务记录读取所有项目的本地任务，显示导入、解析、索引和按需模型任务，不再嵌套在项目文献区域。
3. **右侧阅读工作区**只处理当前论文，提供论文概览、章节精读和论文问答三个板块。原“项目文献”列表被移除，论文列表不在右侧重复展示。

论文导入在两个位置可达：左侧当前项目操作和项目空状态。导入表单继续支持本地 PDF 与 Zotero，解析、章节识别和 FTS5 索引的本地边界不变。论文分类仍作为本地项目偏好，在论文阅读标题区调整，不进入模型和数据库。

## 取舍

- 任务记录不再作为项目页面的折叠区，避免把系统活动误认为项目内容；用户仍可从论文未完成提示和项目空状态进入任务中心。
- 右侧不再重复显示论文列表，减少同一数据的两处选择状态；左侧项目树成为唯一论文导航来源。
- 导入动作在项目树附近可见，但仍要求先选择项目，避免导入到错误项目。
- 不新增数据库迁移，不改变 PaperCard、LightGraph、章节导读、证据问答或模型用量契约。

## 验证

- 前端 Vitest：6 个测试文件、41 项通过。
- TypeScript、ESLint、Vite 生产构建通过。
- Windows NSIS 安装器静默安装验证通过；sidecar smoke 与匿名 PDF 本地解析通过；真实模型调用为 0。
