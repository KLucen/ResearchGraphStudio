# ADR0024：可读问答来源、整组阅读与已保存内容生命周期

日期：2026-11-04（Asia/Shanghai）。状态：P4 用户反馈修复增量；实际检查与交付状态见[反馈验收报告](../archive/reports/p4-query-feedback-verification-20261104.md)。继承[ADR0022](0022-query-foundation-and-versioned-context.md)和[ADR0023](0023-grounded-query-and-explicit-saving.md)，不进入 P5。

## 问题

用户安装 P4 包后反馈：来源预览缺少中文要点，回答引用主要露出内部短 ID，保存对象的“查看原问答与引用”没有可见反馈；问题、来源、回答和保存操作分散，保存后也无法添加个人批注或移除。

内部 ID 仍承担定位、依赖和审计职责，不能用它代替用户需要阅读的原文与解释。修复不得重写冻结上下文、历史答案或模型 raw，也不得为了补一段显示文字自动增加模型调用。

## 来源表示与冻结契约分开

在来源和用途终验通过后，程序生成本地只读 `presentation`：按命中 `entry_id` 和上下文 `ref` 提供题名、准确原文、已有中文摘要、页索引和章节路径。它位于 QueryRetrieval / QueryPreparation 的顶层响应，不加入旧 `snapshot`、检索清单、`input_hash` 或模型请求；旧无此字段的快照和幂等指纹保持。

知识命中的原文优先取其已验证关联证据 quote，不把检索索引拼接串或数据库 ID 当原文。中文要点复用已保存的抽取辅助翻译，标记 `summary_origin=extracted_translation`；原语言证据仍为权威。没有已有中文摘要时明确显示缺失，不伪造翻译、不为展示单独发出请求。回答区域可把已经终验的中文答案作为“本次问答中文要点（AI 综合）”呈现，但必须与来源原文和抽取辅助翻译区分。

知识节点引用跨越多页时，合并原文卡片不标为第一条证据的单一页码；各精确证据仍通过引用回查。缺少页码同样不补成“第1页”。

引用仍保留稳定引用编号供核对，正文展示题名、原文、中文要点及可用定位，而非裸 ID。个人资料继续受用途授权约束，不能通过显示投影、历史缓存或已保存对象泄露撤权正文。

## 一次问答作为阅读单元

将问题本身、对应论文范围、来源预览、逐段回答、限制、引用和显式选段保存组织在同一问答阅读区。历史选中后恢复这一组内容，不把新的输入框问题错误地当作历史答案的问题。

“查看原问答与引用”按保存对象的 `source_query_id` 读取实际准备记录及答案，再定位和聚焦到原问答区；异步加载、来源失效或读取失败均提供可见状态。跳转不触发重新生成、保存或收费调用。原问答失败或来源现状不足时如实提示，保留保存记录的历史身份，不伪装为一次新成功回答。

## 个人批注和移除

0014 加性新增 `query_saved_preferences`，以 `saved_id` 关联已保存对象，保存 `annotation`、独立 `revision`、`removed_at` 和 `updated_at`。旧 `query_saved_knowledge`、文档版本、逐段 manifest、QueryRun / QueryModelRun、答案、raw 和论文根证据不变；没有偏好行的旧对象按空批注、元数据版本 0、未移除解释。

批注是用户对该保存对象的个人说明，不改模型原文或作者主张，不进入 read_passages / 检索 / 上下文 / 模型请求或科学根依赖。它可在本地保存对象中查看，`include_personal=false` 不因此隐藏该批注；该开关仍只控制来源私人笔记等用途授权，不能被理解为批注外发许可。批注编辑和移除都经 KnowledgeStore，使用 Idempotency-Key 与 `expected_revision`；冲突明确拒绝，事件使用审计路径，不推进科学 GraphRevision。

移除表示从当前已保存阅读库撤下，不是删除论文或抹除执行历史。移除对象从列表、后续检索和独立衍生图层排除，直接读取返回明确 `QUERY_SAVED_REMOVED`。移除的已保存段落在后来追加形成的文档副本中同样不再作为有效检索来源；不相关的追加段落继续可读。依赖该对象的后续内容须重验其保存谱系，不得靠展开根证据绕过已移除状态。既有答案历史保留，不能继续作为可复用的有效来源。

退休映射以文档身份与段落 local_ref 共同定位，不能让同一回答另存到独立文档的内容互相误伤。旧0013保存对象未显式记录中间谱系时，从原问题、答案与冻结引用建立只读投影并核对原有哈希；不改旧manifest。无法恢复的对象标为来源无效，保留记录且不影响其他合法保存内容，不将空依赖当作核验成功。

相同已移除保存指纹不能再次返回一个界面不可见的“保存成功”。当前不提供隐式恢复或物理清除；重复操作必须返回明确的已移除状态。移除不是科学审核，也不修改原论文 Claim、核心选择或布局。

## API 与迁移边界

新增 `PUT /api/v1/projects/{project_id}/query/saved/{saved_id}/annotation`，正文为 `{annotation, expected_revision}`；新增 `POST .../remove`，正文为 `{expected_revision}`。两者沿用项目/用途/本机鉴权与 Tauri 白名单，批注最多 12000 字符；保存读取增加 `annotation`、`metadata_revision`、`removed_at`。

升级前自动备份，迁移只加偏好表；旧 0013 保存行及其哈希必须逐项保持。宿主、健康检查、脚本和包内 Schema 一并更新为 0014，避免启动握手不匹配。测试使用隔离数据，不能直接升级用户正式库作实验。

## 验收与后续边界

验收覆盖可读来源与缺少中文要点、旧冻结哈希、整组历史切换、异步原问答导航、批注并发/幂等/重启、移除后的列表/检索/衍生层/依赖/重复保存、0013 升级与原始记录保持。自动化、打包宿主和用户安装反馈分别记载；旧 P4 包的通过项不能代替修复包的用户确认。

本增量不增加模型调用，不启动 P5 Lint/Wiki 发布，不修改 Obsidian 私人文件，也不把展示摘要当新的科学证据。
