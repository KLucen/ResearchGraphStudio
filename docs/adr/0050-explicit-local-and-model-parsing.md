# ADR0050：显式选择本地或模型解析及后续重解析

日期：2026-11-18（Asia/Shanghai）。状态：已实施，实测结果见本轮验证报告与 progress。

## 用户范围与问题

用户反馈勾选模型生成/联网后仍提示未声明 PDF 能力，并明确要求恢复导入时的本地解析选项、本地失败重试，以及已有论文后续模型解析。此要求覆盖 ADR0047 的“新导入仅模型优先”界面限制；显式选择模型后的失败仍不静默切换本地解析。

根因是两个独立问题：联网授权不是文件输入能力；后端保存 profile 时重置 capabilities，前端编辑提供商时也用 defaults 覆盖参数，并且没有文档能力设置入口。旧文本连接测试成功不代表能接收 PDF。

## 决策

1. 默认本地解析。PDF/Zotero 没有选择模型时，不发送 post-import plan，使用已有 PyMuPDF、章节和 FTS5 路径；不创建模型任务、不调用模型。模型概览/精读和翻译选项只在模型模式下显示。
2. 每个模型可声明该端点实际支持的 PDF/文档输入及当前实现的 Chat Completions 文件内容传输；多模态单独明确。文本模型不因勾选而获得文件能力，不按别名或连接测试自动推断。
3. 增加全局 `document_parse` 模型角色，独立于既有概览 extraction 和精读/问答 reasoning；无解析角色时明确要求设置，不偷偷继承另一个模型。复用原角色表，无新迁移。
4. 保存 profile 保留明确声明的文档能力，数值限额继续由端点元数据或已有精确适配器决定。用户明确声明优先于 `/models` 自动发现的文档能力，仍可读取数值限额。不能通过手填 source 冒充验证过的供应商能力。
5. 新增 `POST /api/v1/papers/{paper_id}/parse`，mode 为 local 或 model。local 不接受模型计划；model 必须提供选择模型及联网授权的计划。路径仅从当前论文已登记来源或其引擎任务快照恢复，UI 不能提交任意文件路径。
6. 模型重解析创建新 ImportSession，冻结当前解析模型配置和当前授权；不修改旧任务、旧成功结果、旧笔记或阅读标记。旧失败任务“重试”仍沿用旧快照；调整配置后使用“使用模型重新解析”。
7. 本地重新解析显式绑定已有 paper_id，不因相同来源或内容创建第二篇论文；清理后的原 revision 缺少 Chunk 时恢复块和索引、清除清理标记，保留旧 Section/笔记/个人状态。受管副本在原件缺失时可从应用附件目录内读取。
8. 论文工作区提供本地解析/重试、使用模型重新解析、已存在内容的本地/模型查看切换。新任务失败不使旧本地材料不可读，重新生成前需明确发送授权。

## 边界

不自动宣称用户截图中的具体端点/模型支持 PDF；只有实际支持当前文件请求格式的提供商才能完成模型解析。能力声明和固定 JSON 连接测试不替代真实文件兼容验收。既有本地解析的科学精度限制保持，公式/表格可能退化，扫描 PDF 无文本时保留警告。

没有新增数据库迁移，不批量清理用户数据，不恢复已移除的 PDF 翻译运行时，不新增真实模型调用。当前模型 PDF 请求是非流式，进度按实际阶段展示。
