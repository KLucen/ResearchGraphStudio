# ADR0042：本地阅读整理层与一次全文精读任务

日期：2026-11-14（Asia/Shanghai）

状态：采纳；实际验证与交付见 [progress](../progress.md)。

## 背景

用户反馈精读把图内的 `58.0` 和 `T3: Flights` 等短文本当作正文段落。原实现从 Chunk 直接创建精读段落，既未使用 DocumentParse 中的阅读顺序，也未区分标题、表格、图注和图内标签。相邻页的同一段文字还可能被切为两张卡片。

用户随后要求先优化解析与展示，并将默认生成入口改为一次处理整篇文章。此要求覆盖 ADR0041 中“默认选小节范围生成”的交互决策；已有 A02 记录、A01 导读、A03 理解检查和个人状态继续兼容。

## 决策

增加独立、可重建的本地阅读整理层。原始 Chunk、Section、EvidenceSpan、DocumentParse、PDF 字节和已有模型结果不改写。阅读单元保存有序来源块、跨度、原文哈希、页码与坐标；段落组合只影响阅读投影，不把组合后的文字倒写为原始证据。

先使用解析器的版面顺序，双栏按左栏再右栏处理，跨栏标题分隔区域。只有字体、几何位置、段落边界和续文信号共同支持时才组合相邻正文；跨页同样保守处理，不以模型补写过渡句。无法确定的断段保留。阅读段落另有稳定身份及哈希，避免将旧 Chunk 身份伪装为新组合段落。

正文以段落显示，标题以标题显示。识别到的表格、图像区域、图注、疑似图内标签和其他排除材料放入默认折叠的材料区，保留原文及定位、分类依据和处理建议。图像区域识别不等于理解图像；表格检测不等于可靠还原全部行列。不增加 OCR 或图表语义模型调用；内容不可读时建议打开对应 PDF 页核对，保留未知。疑似类别明确标记，不能据孤立数字推断实验结论。

旧论文无需删除或重新导入。首次打开时可从已有本地结构建立阅读投影；显式“重新整理阅读内容”可从登记的原始文件补充图像/版面信息，核对来源字节后使用。原文件缺失或改变时保留已有本地原文，并报告无法完成的检查，不静默绑定新文件。

默认精读入口使用 `A04_paper_reading_notes_v1` / `paper_reading_analysis.v1`。一次显式任务、一次模型请求覆盖当前论文版本的全部可读正文，同时生成段落中文译文、论证批注、原文精确高亮和全文论证摘要。标题、材料区和原始证据在本地读取；模型不重复输出英文，也不另行抽取知识图谱。原 A02 的小节结果作为历史兼容读取，不再是默认逐范围生成入口。

## 容量、缓存与数据边界

发送前对完整正文、结构化请求开销和输出预算做容量检查；超过所选模型已知容量或配置上限时停止并给出具体提示。不得静默截断全文、后台分批、自动增加请求或宣称读完未发送的内容。部分响应只保留独立校验通过的段落，并标记不完整，不能显示为完成全文。

缓存绑定论文版本、源哈希、阅读投影内容与版本、Prompt/Schema 内容、模型和参数。重新整理后内容发生变化，旧笔记保留并显示过期；仅更新时间变化不应让缓存失效。发出请求前持久化占用唯一请求槽；GET、重启、取消和重复 worker 不自动再发送。每次实际请求进入统一用量账本，未知 usage 或金额继续保持未知，估算与实测分开。

`lite0010` 仅增加阅读投影和全文精读记录表，沿用升级前自动备份。不重建数据库，不迁移或删除外部 Zotero/PDF。当前阶段不恢复完整 Knowledge Engine、Lint/Wiki 或已撤下的 PDF 翻译服务。

## 验证与限制

使用可分发或自造的 PDF 验证双栏、跨页续文、真实新段落、图表/图注/标签、坐标/哈希、旧数据保持、版本失效、全文覆盖、容量拒绝、单请求、缓存、取消与重启。前端验证正文/标题/材料区的真实渲染及窄屏布局，安装后验证本地流程零模型。真实用户文献的复杂版面质量与真实模型成本必须另行验收，合成 Provider 不代替科学质量验收。
