# ADR0051：文档独立超时、真实请求诊断与 PDF 页面图片输入

日期：2026-11-18。状态：实施，真实供应商与科学质量待验收。

## 问题

用户的火山方舟文档导入在90秒失败，详见[只读调查](../document-timeout-investigation-20261118.md)。文档请求沿用文字任务90秒，整篇非流式结果等待较长；四种HTTP超时文案相同，原记录无法判断卡在连接、上传还是等待结果。本轮为明确支持图片理解的模型提供页面图片传输；用户当前模型与两个套餐端点的真实兼容仍待验证，手动声明不能代替能力和传输核验。

## 决定

1. 增加文档独立参数：`document_timeout_seconds` 默认600秒、范围30–1800；`document_total_timeout_seconds` 默认1800秒、范围60–3600，总时限不得小于等待超时。文字任务仍使用原参数。界面按模型编辑，不静默修改正式配置。新文档任务为旧profile补默认；已冻结旧任务保持原参数，重试不重写历史。
2. 增加显式 `document_transport=chat_images`。必须同时声明图片输入和多模态能力，`/models` 不自动启用。现有 `chat_file` 保留，用户可以继续选择端点支持的PDF文件方式。
3. `chat_images` 只在本地渲染完整PDF页面，不调用本地文本/OCR/公式/表格抽取。使用144dpi彩色JPEG和原始页号，按原顺序发送 `image_url`。模型恢复跨页章节、正文、公式和表格，结果仍保存原 `llm_document_*` 层。
4. 当前版本仍是一次完整有界请求，不自动多次收费或分页重试。软件上限为PDF50MiB、128页、单页800万像素、总1.28亿像素、页面图片累计32MiB。超过任一限制则拒绝整份发送，明确建议拆分文件或使用兼容文件接口，不静默截页。以上是本机资源边界，不宣称供应商容量已验证。
5. 请求保持非SSE的JSON协议，但用HTTP分块读取记录真实连接、上传完成、等待响应与接收阶段。任务面板显示已运行时间、页面准备数和阈值，不以页面准备数冒充模型解析百分比。连接/读/写/连接池/总时限分别解释。
6. `Job.result.document_request` 仅保存白名单数字、时间和枚举，无需新迁移。记录真实开始时间、耗时、输入/响应字节和失败阶段；不存正文、Base64、密钥、文件路径或任意供应商错误正文。章节结果完整校验前不发布，模型截断明确失败。
7. 真正发送前仍检查任务状态；渲染页间检查取消，终态任务不因延迟进度回调重新成为running。已发送请求无法从供应商撤回，取消后不发布结果。不自动降级传输或重发。
8. 火山和腾讯精确套餐地址显示“应用推荐解析配置”，用户主动点击后选择页面图片、600/1800秒和 `reasoning_effort=none`，明确需要端点支持。不按模型名称自动赋予能力；推理参数影响该profile全部新任务，用户可以建立专用解析profile。

## 操作与边界

保存设置后，使用论文页“使用模型重新解析”读取当前配置；旧失败任务“重试”沿用旧快照。不会替用户改正式库配置或自动重发此前超时论文。完整论文按页分批、批次检查点与跨批合并是后续工作，当前不宣称已实现。

离线回归和隔离安装证明软件控制流与数据保护，不证明供应商接受图片、实际不再超时或公式表格识别质量。本轮真实模型调用为0；已有用户任务费用保持未知。
