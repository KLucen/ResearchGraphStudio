# ADR0068 · 联系汇报中的详细关系总结

日期 2026-11-22（Asia/Shanghai）。承接 [ADR0060](0060-durable-research-knowledge-library.md)。

旧 Prompt 要求中文解释、双侧依据、差异说明和带关系引用的摘要。用户希望图谱使用简短联系说明，联系汇报能回答两篇论文的关系为什么成立、比较在哪些条件下有效。

新联系任务冻结 `knowledge-connections-2`、Prompt 和 Schema 指纹。每条联系在同一次模型响应中产出图谱使用的简短解释和限制，以及汇报使用的双方材料概括、具体对应点、比较条件及可选 AI 核查问题。详细内容引用该条关系选择的双方节点依据。作者陈述和模型综合分别描述，未知条件显式留缺。程序复验两侧引用、结果结构和当前来源，汇总仅引用实际发布的联系。查看 [Prompt 原文](../../services/engine/researchgraph/knowledge_connections.py)。

已冻结任务按原 Prompt 和 Schema 执行及复验。旧汇报可按原字段阅读，普通分析按现有账本复用相同运行或论文对结果。用户在未归档论文的当前版本上明确授权并选择“重新分析并生成详细汇报”后，按当前候选范围与预算创建新任务，结果另存。新旧关系记录可同时存在，地图对同一组有向端点和关系类型保留一条边。通常显示最新记录，从指定汇报定位时绑定该条汇报的关系记录。

新增字段保存在原汇报 JSON 中，模型响应、候选快照、请求计量和旧汇报使用已有的持久化边界，数据库 head 为 `lite0018`。
