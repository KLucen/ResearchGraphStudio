# ADR0044：版本化章节修复与可折叠文章目录树

日期：2026-11-16（Asia/Shanghai）。状态：采用。

## 问题

用户反馈目录从第一章跳至第五章，并要求一级、二级、三级标题分别展开和收起。只读核对反馈对应的 PDF 后，确认原文并未缺页，而是多个本地解析问题叠加：非粗体混合字号的小型大写标题漏识别；退化表格网格覆盖正文并吞掉小节；印刷目录的编号、题名和页码被当作正文标题。原侧栏只按 level 缩进，未使用 Section.parent_id 构建真实树。

## 决策

1. 解析 Schema 保持 `pdf-structure-1`，解析器身份增加 `structure-v2`。结合字体、编号、行距、位置和书签保守识别标题；同基线分离的编号与题名按几何关系组合。印刷目录标为 `contents`，退化表格只拒收其网格结构，保留原始文字和图形定位。
2. 原始块中的多个标题使用精确 `heading_candidates`，记录字符起止、原文、级别、角色、坐标和章节引用。阅读投影验证每个候选的类型、原文范围及持久章节身份后拆分展示；不生成或改写来源文字。References 和其后的附录按各自片段分类。
3. 显式“重新整理本地阅读版面”只读已登记且 SHA 相同的 PDF。逐块核对保存的原文、坐标和块身份后，增量添加新的 DocumentParse 和 Section；保留旧解析、章节、Span、模型输出和个人状态。当前目录只返回当前解析的树；历史 Section ID 仍按其原始来源读取。数据库 head 保持 `lite0010`，不运行数据重建或迁移。
4. 阅读投影升为 `reading-document-2`，旧投影和笔记保留。投影身份变化使旧全文笔记显示过期；不会自动重新生成或收费。来源不可用、字节变化或原始块无法精确匹配时保留已有结构并提示。
5. 当前章节与旧 Span 之间通过当前解析的块映射关联，Span.section_id 不改。一个旧块跨越多个小节时，章节导读和问答只能使用完整来源块，并附 `source_boundary` 说明，不宣称其为精确的小节文本。跨入排除章节或 References 的混合块不用于新的章节模型请求和索引。全文阅读投影则按已验证字符范围精确分型。
6. FTS 仍每块索引一次；章节查询按验证后的块集合过滤，不复制证据，不把检索命中的原始归属伪装成新身份。普通及历史非混合输入不因附加空字段改变指纹。历史问答结果读取其冻结来源，不能用新版分类重写旧答案；旧进行中任务的输入变化则在外发前失败。
7. 精读和问答共用真正的目录树。优先使用 parent_id，缺失时才按 level 回退；循环、自引用及缺失父级安全回退。每个有子级的标题独立折叠，标题点击继续负责导航，折叠不隐藏正文。当前位置变化和“定位当前章节”展开其祖先；普通重渲染尊重手动收起。保留窄屏面板与阅读字符锚点。
8. 刷新目录后失效的旧章节选择、检索结果与发送授权清除；晚到响应按请求开始时的章节与范围归档。目录和刷新均为本地操作，不触发模型。

## 边界与代价

保留原始块使新旧章节可以兼容，但同块多小节的章节上下文仍较宽，不是段落边界迁移。旧章节的个人状态不自动转移到新章节；旧结果和状态保留。当前树与历史树并存会增加少量本地数据，不定期清理历史。

标题与表格识别仍为保守规则，特殊字体、复杂版面和无文字扫描页不能保证全部正确。本轮不实现公式 OCR、LaTeX 恢复或图片分析，不恢复旧完整 Knowledge Engine。
