# ADR 0027：Query 冻结版式风险与数值回答保护

- 日期：2026-11-05（Asia/Shanghai）
- 范围：P4 Query 验收发现的数值错误；不进入 P5
- 状态：本轮实施，实际验证以 [P4 最终验收](../p4-final-acceptance-20261105.md) 为准

## 原因

真实十题的引用身份、offset 和 Schema 均通过，但一段回答把 PDF 上标压平后的字符串作为普通整数。只读核对源文件哈希、完整页面和字形几何后确认是实际数值误读。既有阅读选择已通过 `reading_evidence_quality.layout_context` 呈现这类风险；Query 能检索未入默认图候选与原文，未继承该风险，不能将“未入核心图”误当作“不能在问答中出现”。

不能修改旧 Chunk/Span、将旧候选数字猜改成指数，或用新的 Prompt 覆盖旧执行谱系；也不能靠模型 Schema 通过宣称科学内容正确。

## 决策

1. 新准备的 Query 在冻结上下文中包含来源绑定的数值版式信息，复用既有只读布局检查：明确区分已检查、存在风险、部分覆盖与未知。只依据与不可变文本/坐标/来源匹配的解析，不猜测修正值。
2. 新 P07 使用独立 v2 Prompt；模型仍输出同一语义 DTO，不增加数据库 ID、坐标或执行能力。风险行及相邻字形提示帮助模型回答无歧义部分；不能确认的数字留未知，不猜整数、指数或单位。
3. 程序终验对明确风险字形对形成的压平数值做保守检查；若回答把该危险 token 作为独立数值输出，返回稳定 `QUERY_NUMERIC_LAYOUT_UNRESOLVED`，保留原 raw 和请求槽，不自动重发或偷偷改写答案。此规则是特定风险保护，不是通用数学/科学正确性证明。
4. 版式上下文进入新输入哈希并在发送、返回、GET、保存和恢复时重新核验。旧无版式字段的清单按旧方式重建；旧 v1 Prompt、manifest、签名、ModelRun 和答案保持可读，不自动升级或重新收费。
5. 来源展示可以只读提示现有版式风险，独立于历史科学内容和输入清单；风险提示不把错误旧数值改成另一个未经确认的数值。没有布局的来源明确未知，不能标为检查无风险。
6. 旧 v1 答案仍可读取，但新执行的显式保存要对用户实际选中段落作当前版式检查，拒绝已知危险数值；未选中的错误段不阻止其他有据段落保存。此门槛也适用于幂等重放，不能借旧签名绕过新写入验证；已保存历史、原 raw/hash 不重写。
7. 真实 v2 补验发现模型在专用 `limitations` 中列举危险数字并明确否定，原守卫保守误拦。程序绑定时仅对限制说明里的危险 token 作带审计的确定性占位显示，不推测其正确数值，也不改正文或 raw；显示程序处理提示。正文中的危险数值仍拒绝。输入/Prompt/计划不变、完整 raw 经全部终验已可用时，允许明确执行零调用恢复；不因历史错误码而再次付费，也不自动重发。

## 限制与验证

检测可能对脚注、上下标和特殊字体给出保守警告，不能恢复全部公式或表格，也不能取代对原 PDF 的核验。没有可靠布局时不产生“已确认无风险”结论。历史答案不被静默重写，真实验收中的失败样本保留；受影响问题的修复补验单列，不从原十题分母中移除。

专项覆盖风险数字拒绝、其他有据回答、未知布局、布局变化失效和旧 v1 零调用恢复；完整回归、真实目标题、冻结引擎和安装器结果在实际报告记录。全程不修改原始 PDF/Zotero/私人笔记，不增加迁移或科学审核队列。
