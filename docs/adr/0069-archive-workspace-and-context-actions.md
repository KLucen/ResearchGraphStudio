# ADR0069 · 归档管理与场景操作

日期 2026-11-22（Asia/Shanghai）。承接 [ADR0060](0060-durable-research-knowledge-library.md) 和 [ADR0067](0067-knowledge-map-display-and-fullscreen.md)。

## 归档生命周期

主导航新增「归档管理」，按类型查看、恢复和逐项确认彻底清除。现有项目论文、论文知识、知识专题、模型提供商、模型配置和旧本地解析的删除入口改为归档。任务记录可归档终态任务。`lite0019` 增加统一归档记录，将旧版已归档的论文知识纳入管理。

归档后，正常列表和可执行操作按对应类型过滤。旧解析是可重建的派生内容，归档记录暂存清理意图，用户仍可阅读已解析材料，直到在归档管理确认清除。论文清除前使用已有备份与引用检查，引用模式的 PDF、Zotero 原件和独立知识的归属按已有规则处理。本机受管文件暂时占用时，清除条目保持可继续清除状态。归档提供商保留本机安全存储的凭据，暂停相关模型配置及用途。恢复只补仍空闲的用途，彻底清除时按共享引用处理密钥。

任务清除后从历史列表永久移除。已发布结果、依赖所需的任务身份和已消费请求继续用于核验与计量。可安全独立清除的存储诊断记录允许删除数据行。已归档任务须恢复才能使用可用的重试入口。

## 知识地图与右键

知识地图默认展开当前页论文，每页 12 篇。用户可分别显示研究问题、概念、方法、贡献和结果，也可切换仅看题名或某一篇。过滤复用当前画布，暂时隐藏的节点位置和固定状态随布局保留。地图分页和节点类型只影响浏览投影，关联候选继续使用知识库比较策略。

右键菜单依附项目、论文、任务、归档条目、知识库论文、汇报、模型提供商卡片及图谱交互区域。菜单复用已有业务操作，依据对象状态启用。键盘支持 Shift+F10、方向键和 Esc。输入区和已选中文本沿用系统菜单。
