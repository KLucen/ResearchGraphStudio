# ADR 0037：翻译服务的按需自动启停

日期：2026-11-11（Asia/Shanghai）

状态：历史记录；翻译功能已于 2026-11-12 按 [ADR0040](0040-remove-pdf-translation.md) 撤下。以下保留原决策与当时的验收边界，不作为当前使用说明。

## 背景

[ADR0036](0036-optional-pdf-translation-bridge.md) 采用用户独立安装并运行本机 Server 的桥接方案。每次翻译前手动启动窗口、确认空闲、任务结束后再关闭服务，增加了日常操作负担。用户希望保留已有模型配置与排版引擎，同时让应用按需管理专用服务。

本决策增量覆盖 ADR0036 中“只能连接用户手动运行服务”及“无法停止外部实例”的适用范围。原有来源校验、模型代理、预算、逐请求用量、缓存、译文质量和手动服务边界继续保留；不会把此前合成测试或旧安装包验收改记为本轮成绩。

## 配置与迁移

翻译设置增加 `launch_mode=managed|manual`、`python_path`、`server_path`。界面提供“按需自动启停（推荐）”和“手动连接服务”。自动模式一次保存 Python 解释器和 `server.py` 的绝对路径，支持浏览选择及手动粘贴。外部 Server 4.1.8、完整 pdf2zh_next 环境、字体及其他必要资源仍由用户在工程之外独立安装，应用不创建翻译环境或修改外部源码。

`lite0007` 为加性迁移，升级前沿用 SQLite 备份机制，保留论文、阅读结果、译文与用量。已有翻译设置补为 `manual`，不擅自改变旧服务的所有权；无设置行的新安装推荐 `managed`，但不会因此启动进程。旧配置用户需要主动切换模式并补齐路径。

## 启动边界

GET、读取译文、读取缓存及配置预检不启动服务。自动模式检查本地路径、脚本版本与端口可用性；配置检查成功不证明 Python 包、字体、排版模型或实际翻译环境完整。

只有用户提交非缓存翻译、确认 PDF/文本处理与专用服务授权，且来源、模型、模式、路径和预算仍匹配预检指纹后，才由应用无窗口启动专用实例。已有端口被占用时拒绝启动，不接管、复用或终止该端口的实例。自动任务继续只支持整篇英文到简体中文，同时生成中文和双语 PDF。

创建任务时冻结启动模式和路径到 `runtime_snapshot`；之后修改设置不会改变已排队任务的启动配置。健康检查、提交、轮询及其历史回退、下载的每次 HTTP 请求前重新检查自建进程及监听端口归属。失去归属时以 `TRANSLATION_RUNTIME_OWNERSHIP_LOST` 停止，不向替代服务继续发送论文或代理票据。

托管启动禁用外部工具的环境创建及源码更新。外部 Server 的启动代码仍可能检查上游通知，首次使用的排版模型等资源也可能下载；不能宣称外部启动完全不联网。模型请求继续经过冻结配置的一次性本机代理，真实 API Key 不交给外部工具。

## 进程所有权与结束

应用只管理自己启动的进程树。Windows 使用带 kill-on-close 的 Job 承载自建服务及其子进程，在引擎硬崩溃、句柄关闭时回收该树；不将已有手动实例加入 Job。

Windows 创建进程时通过 Job List 原子加入专属 Job，再恢复挂起线程；仅继承 NUL 标准句柄，无命令窗口。停止时在有界等待内查询 Job 活动进程数，无法确认整树退出时返回 `TRANSLATION_RUNTIME_STOP_UNCONFIRMED`，不发布成功。路径解析前后均拒绝 UNC，不能用父目录 junction 绕过本机路径限制。

正常成功路径先下载、验证并保存译文，然后关闭自建服务树，最后发布 `COMPLETED`。失败、取消及应用正常退出同样撤销代理票据并回收自建实例。界面显示启动和关闭服务阶段，不把“已发送取消请求”冒充已完成所有清理。供应商已接收的请求仍可能计费，进程退出也不等于删除外部目录中的 PDF、副本或日志。

`manual` 模式继续只连接用户运行的专用实例。取消或退出阻断本应用后续模型请求，但不负责终止手动服务，外部排版可能继续。重启不自动续发中断任务。

## 验证与质量边界

本轮真实模型调用为 0。自动化使用匿名 PDF、合成服务和合成 Provider 验证路径配置、预检零启动、进程所有权、任务状态、清理、缓存与用量，不据此宣称真实外部引擎或 PDF 翻译质量通过。实际执行命令、测试和 Windows 交付结果以 [进度](../progress.md) 与 [开发日志](../../DEVELOPMENT_LOG.md) 的本轮记录为准。

译文仍为独立阅读辅助文件，不替代作者原文 Span、证据检索或 LightGraph。设置和使用方法见 [文献翻译](../pdf-translation.md)。
