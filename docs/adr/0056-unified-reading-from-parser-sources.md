# ADR 0056 — 本地与模型材料共用论文概览和全文精读

日期：2026-11-19（Asia/Shanghai）

状态：已实施，验证结果见本轮报告。

## 问题与诊断

本地解析保存在 AttachmentRevision/Section/Chunk 与阅读整理层，模型解析保存在 llm_document_parses/segments。两者分表本身不是错误；模型路径在 Papers 中改走独立 ModelDocumentPanel，旧后处理只接受 summary/sections/translations，因此既没有 PaperCard/LightGraph，也没有逐段标注合同，公式直接显示为 pre。

本轮对正式库进行 mode=ro/query_only 的元数据诊断：最近成功会话实际冻结 overview=true、reading=false、translation_mode=none；其输出为无 schema_version 的旧摘要。保存材料含74正文段、8个带LaTeX公式、1个结构化表格、3个图及3个图注；quick_check=ok、外键违规0。该记录不能证明用户手动勾选过概览；前端 defaultPostImportPlan 实际默认 overview=true，是无需额外选择就生成概览的入口原因。未读取或导出论文正文、原始响应、PDF或凭据。

## 决策

1. 分开材料身份，统一功能与渲染。模型材料不伪造成旧 Chunk、EvidenceSpan、PDF坐标或哈希核验结果。本地/模型概览共用 PaperOverview、PaperCard 与 ForceGraph；精读共用 ReadingContent 中的段落、译文占位、论证高亮、批注和安全KaTeX组件。模型原文明确标识为提取稿。
2. 新导入概览、精读默认都不选，翻译默认none。ImportPlan冻结 postprocess_contract_version=2；旧缺字段的计划仍用原协议，原始计划、历史输出与已成功批次不重写。页面显示当次保存选项，打开或切换来源不请求模型。已有模型材料支持显式补生成概览、精读或译文，无需再次上传PDF。
3. 模型概览采用现有 paper_overview_graph.v1 联合合同。原始模型短ID先经现有图关系、枚举、数量及禁止字段验证，再绑定程序生成的论文稳定ID。已保存稳定ID必须幂等复验且属于当前论文。坐标与相机只存新的本地布局表，不成为模型语义。
4. 精读采用 model-document-reading-1，复用现有五类高亮、段落功能与全文论证结构。paragraph_id只能引用当前parse中完整、有序的正文segment ID；引文与occurrence必须精确存在，不能虚构图谱节点。none模式不允许夹带译文。model-document-translation-1独立返回逐段身份、章节、完整原文和译文，逐项绑定；相同文字的不同段落不能合并。公式、表格可作为阅读背景，仍保留不确定性。
5. 旧摘要不自动变成图谱或高亮。历史内容保留，明确提示缺少新版结构；用户重新生成后才能得到新功能。生成新结果保留旧结果。编辑材料推进其本地版本时间并使已有生成结果stale；等待模型期间以及发布事务内均重新核对源材料与归属。
6. 所有新解析/后处理使用严格JSON解码，拒绝重复键、NaN/Infinity和Schema外字段。模型解析加强章节身份、有限数值及已知定位形状检查；validated批次与最终发布继续复验。模型不能生成SQL、路径、正式ID或执行操作。
7. 失败材料本机保存，日志和普通诊断只记录安全字段路径/错误类型。批次格式失败新增独立私有失败表；用户报错后可明确授权一次文本格式修复，不重传PDF，不重做成功批次。必须有可解码、可证明保持原材料的失败响应，修复不能改正文、公式、表格或抹去不确定性；不可恢复材料须明确重试该批。
8. 概览/精读/翻译的正常响应若契约失败，同样保留raw并提供一次显式修复。绑定原parse/源版本/失败output与新Job，发送前持久记账；修复后的失败不能再链式修复。网络失败、无raw、来源变化及数据库完整性错误不开放此动作。修复只生成新DTO，不能让模型修改数据库结构或执行修复代码。
9. 修复请求及生成请求的槽位、Token和未知费用均计入用量；取消/崩溃也保留已发送记录。成功批次的事后格式修复只保存该检查点，用户另行继续剩余任务；不会在修复结束后隐式上传余下PDF。普通重试预算不把纯文本修复的worker次数误算成PDF抽取次数。

## 数据迁移与边界

lite0014加性增加私有失败响应表及模型图谱布局/视口表，升级前自动备份，已有论文、源文件、笔记、批次和历史结果保留。隔离库验证升级与失败回滚，不使用正式库试迁移。不增加SHA-256解析前置条件。

共用展示不表示两种提取稿逐字等价，也不表示模型高亮、翻译、公式或科学结论已经真实验收。已有旧本地精读的来源预览与局部证据问答仍按其原核验方式工作，模型提取稿不能冒用这些来源凭证。真实端点兼容、识别质量、翻译质量及用户原生桌面反馈单独记录。
