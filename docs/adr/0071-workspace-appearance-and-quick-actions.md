# ADR0071 · 工作区排版、交互与本机外观

日期 2026-11-22（Asia/Shanghai）。实施 [界面优化开发方案](../ui-optimization-development-plan-20261122.md)，沿用 [引文定位与本机恢复](0070-knowledge-excerpt-references-and-quote-recovery.md) 的业务接口。

## 显示与操作

论文的阅读页签旁直接显示当前解析来源。只有双来源允许切换，继续使用已有本机记忆。重新解析放入「更多操作」。有论文概览或精读结果时，生成和维护操作放在各自的次级入口。卡片分类数量采用同一组浏览状态和搜索条件。

地图的显示类型移到画布上方。悬停或键盘聚焦临时强调关系两端，拖动和平移抑制临时反馈。精读编号和汇报依据使用同样的交互区分，悬停或聚焦提示对应内容，点击保留原定位行为。临时高亮不写布局或已读状态。汇报显示双侧出处，跳转地图时临时加载对应论文，返回恢复原项目、专题、搜索和分页。

任务记录将失败原因和可执行恢复置于主要区域，请求与校验细节置于「诊断详情」。归档条目显示可用项目名，恢复为直接动作。彻底清除由菜单打开确认框，取消默认获焦，关闭后焦点返回已存在的触发控件。沿用既有归档和本机恢复接口。

## 外观偏好

「设置与诊断 → 外观」提供跟随系统、浅色和深色。应用同源启动脚本从本地 WebView 存储读取 `rgs.appearance`，在 React 首次渲染前设置主题。React 侧复用相同值规则并监听系统配色变化。无记录、值无效或读取失败时跟随系统。浏览器清除应用存储会重置偏好。

`appearance.css` 提供两套共用颜色，包括原生输入 `color-scheme`、焦点、语义状态、图谱和精读标记。React Flow 复用同一主题。PDF 图像保留原色。主题切换仅修改前端外观和本机偏好，无新数据库字段、模型请求或桌面宿主权限。实际回归及安装包见 [进度](../progress.md)。
