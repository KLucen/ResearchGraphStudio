# ADR0073 · 专题管理、专题外联系与工作区搜索

日期 2026-11-23（Asia/Shanghai）。版本 `0.0.3`，沿用数据库 head `lite0020`。承接 [独立知识库](0060-durable-research-knowledge-library.md) 和 [统一归档](0069-archive-workspace-and-context-actions.md)。

## 专题与成员

知识库工具栏提供专题管理。支持新建、修改名称与说明、查看专题论文及归档，归档专题从统一归档管理中恢复。论文知识列表和单篇详情可以直接打开归类操作。批量选择可跨页保持。加入只增加目标专题成员关系，从指定专题移动会在同一事务内加入目标并解除所选来源中的成员关系，其余归属继续保留。移出只影响当前专题成员资格。批量接口复用幂等账本，验证当前专题和论文状态。

专题是知识库的组织维度。专题变更只写专题元数据和成员关系，保存的知识版本、报告、模型回执和科学关系保持原有身份及证据。归档专题在彻底清除前保留成员数据。历史汇报仍通过既有来源核验和详情入口读取。

## 关系显示

专题视图默认显示当前范围中两端都可见的专题内联系。「显示专题外联系」以当前页为起点，只请求已验证报告中与这些论文直接相连的候选。后端独立排除当前专题成员、归档论文及无当前版本的条目。每页最多展示 12 篇专题外论文，使用空心题名节点和长短虚线。跨专题线仍打开原联系汇报及双侧证据，也可打开相关论文知识。默认视图布局独立保存，临时专题外预览不写回基础布局。翻页和筛选继续限制当前页的主题节点。

## 搜索

`Ctrl+F` 在个人研究空间打开本地搜索，按项目名称、说明和论文题名分页查找。搜索覆盖已存的全部项目与未归档论文。结果带所属项目，选择即可进入对应项目或打开论文。知识库中同一快捷键聚焦当前搜索，在全屏地图中聚焦画布内的搜索框。地图和论文知识匹配题名、备注、研究问题和概念，联系汇报匹配标题和摘要。搜索和专题外联系读取无需模型请求。实际回归及包路径见 [进度](../progress.md)。
