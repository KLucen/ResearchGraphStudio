# ADR 0028：Query 科学指导与可审计引用补齐

- 日期：2026-11-05（Asia/Shanghai）
- 范围：P4 科学部分支持问题；不进入 P5
- 状态：本轮实施，实际结果见 [改进验收](../p4-followup-verification-20261105.md)

## 原因

前次真实验收证明 Schema 和来源身份合法仍可能出现表列对应不足、公式引用不完整、轮次与提议混用、背景被当作贡献，以及限制范围扩大。原文、引用和原始输出必须保留，不能为了提高成绩静默改写。旧 P07 v1/v2 的输入和恢复必须继续按原协议重验。

## 决策

1. 新 prepare 冻结 `scientific_guidance/query-scientific-grounding-1`，依据已经终验的来源生成知识角色、node→evidence→chunk 根路径和已检测表格的完整组。未检测表格明确为未知，不从空格排版推测列或公式语义。
2. 存在新字段时选择独立 P07 v3；只有 numeric_layout 的旧快照仍选择 v2，无两字段的旧快照仍选择 v1。三者使用同一严格输出 DTO，Prompt 的结构规则继续与运行 Schema 自动核对，不额外要求模型填写程序已知身份或坐标。
3. 新 Prompt 要求一个段落表达可独立支撑的科学点，保留原术语及限定，不把相同计数当作概念等价，不把背景当新贡献或把未测条件扩大成普遍限制。公式/表列必要片段或结构不充分时只答有据部分、数量关系留未知；Prompt 不被当作科学正确性证明。
4. 仅新快照在答案绑定时沿被冻结的真实来源链接补齐原文根和已检测表格组，保留模型原顺序并稳定追加来源；不扩展任意相邻内容，不生成新证据或科学关系。补齐后再验引用白名单、归属与私人来源门槛。背景来源允许正常介绍，附“非新贡献”的提示，不统一拒绝合法背景回答。
5. 模型 raw 不改。`scientific_binding` 记录原始/绑定引用、背景提示来源及 raw/guidance/绑定结果哈希，GET、恢复及保存从 raw 重建并核对审计。引用补齐仅表示定位依赖完整，不能将其用于宣称论证已被科学证明。
6. 旧答案、已有保存、旧模型参数/Prompt/hash 不自动升级。KnowledgeStore 仍为显式保存入口，用户没有保存时不产生新的科学知识；不新增迁移或人工审核队列。

## 性能和验证边界

检索优化只减少本调用 NodeEvidence ORM 构造、字符串/证据集合遍历及固定 UUIDv5 前缀和 JSON 编码器的重复准备；UUID、索引字节、完整响应与逐候选/来源/权限验证保持，不建立跨调用缓存。P95 达标以最终共享源码全部样本为准，不能以候选中位数或删除慢样本替代。

匿名测试覆盖持久索引身份、引用闭包/表格组、未知结构、归属及审计、旧 v1/v2 恢复和变源失效。真实补验最多两次新初始请求，旧质量分母和新结果分列。复杂版面、未检测表格、公式语义和跨模型泛化仍有限，未测项如实报告。
