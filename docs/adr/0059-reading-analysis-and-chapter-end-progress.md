# ADR0059 — 直接显示右侧分析与章末阅读状态

日期：2026-11-20（Asia/Shanghai）。状态：实施。按用户安装反馈修正[ADR0058](0058-anchored-reading-annotations.md)的摘录卡和布局决定，验证见[本轮报告](../reading-sidebar-footer-verification-20261120.md)。

## 用户反馈

用户明确不需要重复显示原文的高亮摘录卡；真正的分析批注被这些卡和过早的单栏断点挤到下方。阅读状态应位于每章末尾，读完即可选择，而不用返回章首。

## 决定

1. 移除每处高亮独立的英文摘录卡。原文继续显示五色标记及编号，右侧分析只保留紧凑的类型/编号定位按钮，不重复引文。原始高亮的类型、出现序号和重叠身份仍保持，双向定位和键盘操作继续可用。
2. 每段的一份实际分析直接显示在原文右侧，从正文起点对齐，包含论证作用、核查提醒和阅读问题。整段分析不再等到所有高亮或译文之后才显示；已有整段合同不被伪造成每条高亮独立解释。布局仍按实际阅读宽度观察，在至少560px时保留双栏，只有更窄的区域才按段堆叠，列标题同步变化。
3. 本地和模型精读的大章标题不再放阅读状态。每章所有小节正文和可归属的材料之后显示“章节标题·章末阅读状态”；仍使用原有章节/版本ID保存，目录状态和继续阅读规则不变。小节不新增独立状态。
4. 本地投影可能把图或公式追加在全文数组尾部，显示材料必须按真实章节身份分组，而不能把尾部顺序误认成最后一章。旧重建章节共用原section ID时，仅在来源或范围可以消歧时归属，不能确定的材料独立保留且明确标记。

## 范围

仅调整已有结果的显示、材料分组及阅读状态控件位置；没有数据库迁移、Prompt或模型响应合同变更。已有合法笔记重新打开即可，无须重新生成。正式库、私人PDF与凭据不参与开发测试；真实模型请求0。浏览器与隔离安装通过不代表用户原生WebView或真实论文质量已验收。
