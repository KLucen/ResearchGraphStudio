# ADR0038：随安装包提供翻译运行时与阅读工作区布局

日期：2026-11-11（Asia/Shanghai）

状态：部分已替代；翻译运行时、分发与执行部分已于 2026-11-12 按 [ADR0040](0040-remove-pdf-translation.md) 撤下，阅读工作区置顶及论文信息默认折叠的布局继续适用。以下保留原决策与当时的验收边界。

## 背景

ADR0036 建立可选 PDF 翻译桥接，ADR0037 增加专用外部服务的自动启停。用户进一步要求安装后具备翻译环境，不再自行配置 Server 或 Python 路径；同时要求论文阅读成为主区域，论文元信息收纳到底部，并允许只生成需要的译文格式。

## 决策

默认运行方式改为 `bundled`。Windows 安装资源包括官方未修改的 PDFMathTranslate-next **2.10.2**、BabelDOC **0.7.1**、嵌入式 Python、完整依赖与字体、版式模型、tiktoken、CMap 离线资产。原创本机 adapter 调用官方 CLI，复用已有临时模型代理和受控进程树；不再把 Zotero 插件或 Server 安装作为正常使用前置条件。高级外部模式仍保留 `managed` 和 `manual`，原有路径配置不删除。

选择论文、PDF 解析、预检、查看历史和命中缓存均不产生模型请求，也不启动排版进程。只有用户明确提交翻译才启动随包引擎。PDF 文件及排版在本机处理；模型接口收到待翻译文本和提示，不接收整份 PDF 文件上传。实际外发文本可覆盖全文，因此翻译仍需用户确认和预算，不属于默认零调用解析。

真实 API Key 继续由应用凭据存储管理，只在本机模型代理读取；运行时只拿到一次性 loopback 地址和票据。冻结 Profile 参数、逐请求 usage、失败停发、请求次数与输入估算守卫保持。上游缺失 usage/费用仍记未知，不能把合成 Provider 数值当真实 Token。随包路径使用隔离配置与缓存，原始 PDF 不覆盖，译文不变成作者证据。

运行契约支持 `output_mode=dual|mono|both`。新界面默认双语 `dual`，也可选择中文 `mono`。`both` 用于兼容旧调用和历史；旧请求未提供字段时保持 `both`，旧记录新增列默认同样为 `both`。选项进入预检身份与缓存边界，只校验和发布所选产物；切换输出格式不能误复用缺少相应产物的缓存。既有历史任务保持自己的运行时快照；没有快照的旧任务按 `manual` 解释，不静默切换执行引擎。

页面先显示论文阅读工作区和论文概览、章节精读、论文问答、文献翻译入口，论文信息移到其后，默认折叠。完整标题、分类、来源、文件状态、修订和解析详情仍可主动展开，不占据主要阅读首屏。

## 数据迁移

Alembic head 为 `lite0008`，从 `lite0007` 加性增加 `pdf_translations.output_mode`，未来任务设置改为已启用的 `bundled`。升级前自动备份；不删除论文、章节、图谱布局、已生成回答、旧译文或任务，不重新初始化数据库。旧外部服务地址和路径保留在高级设置，历史任务快照不回写。迁移不启动引擎、不发送模型请求。恢复旧版本应使用备份，不尝试原地降级。

## 分发与构建

`scripts/prepare-translation-runtime.ps1` 读取固定 `translation-runtime-manifest.json`，校验官方 ZIP、完整解压并复制源码和许可资料到默认 `apps/desktop/src-tauri/translation-runtime/`。已有目录只有清单、关键程序/离线资产及来源文件校验一致时复用，否则停止且不覆盖。资源目录及临时目录被 Git 忽略，二进制、第三方源码压缩包不进入源码提交。

官方 ZIP 为 607049119 字节，SHA256 为 `7ac1811b0f82078a86bcce88e185efff75fc55a3752c7f9c015186e5214b3c0b`，与 GitHub asset digest 一致。准备结果保留原始 runtime 和 package license/notice，并附 next、BabelDOC、PyMuPDF、MuPDF、Levenshtein、marisa-trie、SciPy 对应版本源码及构建说明。详见 `scripts/translation-runtime-notices.md`；此材料记录不构成许可兼容性或完整法律结论。安装用户不需要另行下载这些排版依赖。

## 验证边界

本轮真实模型调用为 **0**。运行时准备脚本在 Windows PowerShell 5.1 的完整准备、重复校验及损坏缓存拒绝已实测；这不代表真实翻译质量、实际引擎合成联调或安装后的验收。实际引擎、隔离安装和桌面运行结果由 [进度](../progress.md) 记录，不在本决策提前标记通过。复杂表格、公式、扫描文献及中文排版仍需真实文献质量验收。

ADR0036/0037 保留为演进历史；其中“用户必须独立安装外部环境”仅适用于高级外部模式，不再描述默认入口。
