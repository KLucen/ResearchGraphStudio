# ADR0072 · 任务、工作区与发行可靠性

日期 2026-11-23（Asia/Shanghai）。承接 [独立软件质量审计](../independent-quality-audit-20261123.md) 的第 1、2、3、4、5、6、8 项。版本为 `0.0.2`，数据库迁移 head 为 `lite0020`。

## 任务、授权与来源

队列认领、处理和终态写回独立于 HTTP 路由。普通任务保持顺序，诊断使用独立队列。诊断终态写入遇到 SQLite 短时争用时，仅重试写回。任务异常不可恢复时进入中断状态，既有发送槽承担防重。健康检查提供执行器状态和不受列表分页影响的活动任务数。运行中模型任务的取消在数据库提交后停止本机等待，保留已发送请求及已记录回执。尚未结束的本机渲染和事务继续走安全退出边界。

自动收集、自动联系分别识别自动来源及手动授权，撤回会登记未发送任务的终止条件。重新开启只授权后续新任务。异步准备结束和各批发送前复验当前条件。已持久化的回执和部分结果按原路径读回。HTTP 429 可保存和显示有界 `Retry-After`，仍由用户手动重试。

`knowledge-connections-3` 对新比较中出现的数字要求在选用引文中出现，并按两篇论文各自的引文限制论文侧陈述。v1/v2 冻结请求、成功缓存和原始结果继续读取。引文中的字面数字用于核对，推断、实验可比性和科学准确率继续依赖人工及真实样本验收。

## 浏览与交互

新增全局分页任务和单项目读取，兼容原数组和既有项目路由。项目树增量读取后续论文。知识恢复用可见任务 ID 定向加载诊断。知识库搜索读当前版本的研究问题和概念。打开论文来源可直接读取尚未出现在侧栏页中的项目。侧栏和任务区区分空结果、失败和未知状态。

图谱保存按视图更新缓存并显示可重试错误。桌面宿主只为已经有数量与键长限制的布局路由提高请求体字节上限。WebView 偏好读取失败时可用默认值启动。

## 备份、恢复与计量

「设置与诊断 → 工作区备份与恢复」使用原生目录选择。宿主暂停认领任务，确认无活动任务后执行离线导出。恢复先在独立目录核验数据库、附件哈希、长度和引用，然后启动恢复出的工作区。新引擎健康检查通过后才保存当前工作区指针，原工作区保留。失败可继续使用原工作区。正常启动后旧界面缓存重新加载。

备份包含 SQLite 和应用受管 PDF。外部路径与 Zotero 仅保存链接，API Key 仍在 Windows 凭据库。当前格式恢复同一 schema head 的备份。恢复在新工作区默认关闭自动联网，原有未完成工作须重新确认，并需重新绑定凭据。清除前及迁移前的小型 SQLite 快照保留原通路，由统一函数执行一致性验证和原子发布。常规快照可能保留清除前数据，界面已说明。

`lite0020` 仅新增 `archived_paper_usage`。清除论文前在同一事务冻结经现有逻辑去重的分类计量，并保留项目级与全局汇总。保留项不含论文 ID、模型身份、原始响应或文献材料。旧报表及清除任务原有凭据、文件路径保护照常执行。

## Windows 防护与发行

公式预览以最大许可字节数加一读取，超过上限或指纹变化则拒绝。更新 Pillow、OpenTelemetry API 和 Rust `url` 至公告修复版。`scripts/build-windows.ps1` 的 `-Release` 路径记录 Windows 生产依赖 SBOM 和 OSV 公告，并校验预期发布者的 Authenticode 签名及时间戳。测试包走普通构建。Windows 环境的实际验证范围见 [进度](../progress.md)。
