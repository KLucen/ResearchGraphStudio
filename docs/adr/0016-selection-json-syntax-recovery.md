# ADR 0016：P13 末尾说明数组的单字符语法恢复

日期：2026-11-03（Asia/Shanghai）。状态：本轮实施，定向验证及最终回归/打包分别见 [progress](../progress.md)。保持现有 Prompt、领域 Schema、Alembic 0011 和 complete-context-v1，不进入 P4/P5。

## 实际问题与边界

一条旧任务已完成 P02 34/34、P12 10/10 和前 4 个 P13 选择检查点；第 5 个 P13 的 4359 字符响应不是合法 JSON。原始响应根对象最后的 coverage_gaps 是非空字符串列表，字符串本身完整、最终根 `}` 已存在，但其前遗漏数组闭合 `]`。重新抽取 PDF 或重调成功阶段不能解决已收到响应中的这个标点问题。

JSON 形状损坏不能证明模型语义完整，也不能证明只是供应商传输问题。历史请求未记录 finish_reason，不得反推其为 stop。此次只恢复唯一已观察到的语法形态，不开发通用 JSON 修复，不调用模型重写响应。

## 唯一允许的恢复

仅在 `validate_selection` 的原 JSON 解析失败后识别以下全部条件：

1. 顶层是一个根对象，所有前置键和值均可严格 token 解码，根末唯一字段恰为 coverage_gaps。
2. 该值是非空数组，每个现有元素均为完整 JSON 字符串；字符串内的引号、反斜杠、括号及 Unicode 由 JSON 解码器处理，不用正则平衡内容。
3. 数组最后一个完整字符串后仅余空白和已存在的最终根 `}`；唯一缺失字符是数组的 `]`，插入点等于原解析器报告的位置。
4. 只插入这一个 `]`；不修改、删除、补写或重排任何键、字符串、数值、ID、建议、证据或限制内容。
5. 恢复结果须通过完整严格 JSON 解析，再执行原有 Selection Schema、文献版本/输入快照、根 ID 白名单、来源、选择和 KnowledgeStore 校验。

P13 的正常解析和恢复后解析均使用严格 JSON 解码，拒绝重复键（含转义后同名）与 NaN/Infinity，防止同名字段后值静默覆盖前值。恢复路径另拒绝空数组、尾逗号、缺少分隔符、嵌套数组、非字符串元素、不完整字符串、缺少根 `}`、EOF 截断、coverage_gaps 后仍有字段及其他语法损坏。严格解析与单字符恢复仅用于 P13，其他阶段解析规则不变；这不放宽领域 Schema。未知字段或非法科学内容不能因为括号恢复而被接受。

## 审计与保留

原 ModelRun.raw_output 保持逐字符不变。`ModelRun.parameters.integration_normalization` 记录：

- path=`coverage_gaps`，rule=`close-final-selection-gaps-array-v1`，inserted=`]`。
- offset：从 0 开始的 Python Unicode 字符索引，以字符串形式保存；不是 UTF-8 字节位置。
- raw_sha256 和 normalized_sha256：分别对原始及插入后文本的 UTF-8 内容计算 SHA-256。

审计不重复输出私人正文。原输入、Prompt/Schema 哈希、旧任务签名及阶段检查点不变。语法恢复留痕与模型原始输出分开，不能以恢复后的文本覆盖 raw_output。

## 恢复、调用与费用

旧 P13 非法响应只有在相同输入/签名下通过上述语法识别及完整后置验证后才可复用。已成功 P02/P12 和前面成功 P13 检查点不重调；剩余未完成阶段仍按正常真实请求执行并独立记录用量，不能将零网络回放写成整个任务零费用或真实新生成通过。

新请求将供应商实际返回的结束原因记录到 `ModelRun.parameters.attempts[].request.finish_reason`；缺失或未知按实际保留，不为历史调用补写 stop。不改变输出能力、上下文策略、超时/重试边界或 Prompt/Schema。

## 验证与限制

定向场景包括允许的唯一括号遗漏、字符串内转义/括号/中文、空白和字符 offset/hash；正常及恢复路径均覆盖重复键（包括转义后同名）与非 JSON 常量拒绝，恢复反例覆盖上述损坏；恢复后未知字段、重复根、非法建议和错误 ID 仍失败。还需确认原 raw 保持、旧非法响应复用和已成功阶段零重调。最终回归、真实剩余请求与安装状态由实际报告记录，不因定向测试通过而宣称全部验收完成。

该规则不猜测字符串列表之后是否还有模型未表达的语义，不补全科学论证或缺失知识。全文质量仍须单独验证；所有私有响应、运行数据库、日志与安装器保留在本地受控目录，未经新授权不 Push。
