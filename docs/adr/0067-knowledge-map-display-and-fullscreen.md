# ADR0067 · 知识地图标签与全屏

日期 2026-11-21（Asia/Shanghai）。承接 [ADR0060](0060-durable-research-knowledge-library.md)。

## 节点与标签

知识地图此前沿用 React Flow 默认节点样式，旧阅读画布专属的规则未作用于知识地图。长标题因此在狭窄节点中连续折行，密集节点的文字覆盖彼此。知识地图采用独立的圆形节点样式，论文节点较大。节点和图例继续共用类型颜色。标签在圆点周围择位，保留横排，长标签以省略号收尾。优先放置悬停、选中和论文节点的标签，密集处空间不足的标签收起，节点悬停与详情提供完整名称。

工具栏提供中文、英文和中英双语，默认中文。双语各占一行，相同名称只显示一次。缺少所选语言名称时显示已有名称，论文题名沿用原文。语言偏好保存在本机，图谱和节点详情使用同一套标签规则。

## 全屏和布局

Windows 用主窗口的全屏权限进入原生全屏，浏览器用元素全屏，环境拒绝时画布可填满当前视口。全屏保留画布、图例、工具栏与详情入口。退出按钮和 Esc 返回普通地图，打开的论文详情可先处理 Esc。离开知识地图时恢复窗口与页面焦点范围。

语言与全屏切换共享同一个画布实例、节点身份、物理位置和相机，使用既有图谱布局键。标签布局是显示层数据。切换本身产生 0 次模型请求和布局写入。
