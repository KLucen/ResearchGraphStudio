# ADR 0036：可选的版式 PDF 翻译桥接

日期：2026-11-11（Asia/Shanghai）

状态：Accepted；真实翻译质量与外部引擎端到端验收待完成

## 背景

用户要求在 Lite 中复用 zotero-pdf2zh 的版式翻译能力，并使用软件中已有的模型 API。当前本地解析可以保存文本块、坐标、章节和部分表格，但不是可逆的 PDF 排版引擎，不能单靠这些信息承诺生成与原稿版式对应的译文。

本次审查的外部源码为 guaguastandup/zotero-pdf2zh 提交 `e783bb9ffd5cf3caf0efbb2cfd4d19f8d9f8a09e`，Server 自报版本 `4.1.8`。该方案由 Zotero 插件与独立 Python Server 组成，后者调用 pdf2zh 或 pdf2zh_next。其配置会持久化传入的模型密钥、多个任务共享配置，而且没有停止翻译子进程的 API。健康检查通过也不表示模型、字体和排版依赖已经准备完成。

## 决策

在当前论文工作区增加第四个独立板块“文献翻译”。设置页配置用户独立安装的、由本应用独占使用的本机 Server；默认关闭，只允许 loopback HTTP，不从 WebView 直连外部服务。不捆绑、安装或修改外部项目源码与运行时；本工程仅增加原创的协议适配代码。外部项目使用 AGPL-3.0，若将来决定随安装器分发，须另行核对许可证、说明与对应源码安排。

首版仅支持整篇英文 → 简体中文，使用 pdf2zh_next / OpenAI 兼容文本接口，同时请求中文 PDF 和双语 PDF。当前核对的 Server 接口没有可用的任意页范围字段，因此本轮不展示无效范围选择。服务版本限定为实际审查的 `4.1.8`，其他版本明确提示协议尚未适配。

API Key 继续保留在系统凭据存储。每个翻译任务启动一个独立 loopback 模型代理，外部 Server 只得到临时票据和代理地址。代理只允许冻结模型的纯文本请求，覆盖受控模型参数，不接受工具、文件或图片调用，也不把供应商诊断、隐藏推理或真实密钥返回外部程序。

论文选择、切换板块、GET 与连接设置均不产生模型调用。显式预检只核对来源、配置、缓存和服务状态；预检指纹绑定来源字节、模型配置、引擎和预算，配置变化后须重新预检。非缓存任务必须同时确认 PDF/文本处理授权和专用服务/保留副本说明。

每个实际上游请求在发送前进入统一 Lite 用量账本，收到响应后更新实际 usage；缺失 usage 或价格保持未知。请求数硬限、累计输入的保守 UTF-8 字节估算限额及每请求最多 8192 输出 Token（已知模型能力更低时取低值）共同限制工作量。这些限制不等于供应商费用上限。完全相同的成功请求在任务内复用，错误、超限和取消后撤销票据，不允许外部 SDK 重试继续产生新请求。

## 数据与生命周期

- `lite0006` 加性增加翻译设置与结果表，迁移前沿用现有 SQLite 备份机制，不重建或迁移原论文。
- 原始 PDF 读取时校验实际字节 SHA-256；随机任务文件名避免覆盖外部同名附件。
- 译文是独立派生文件，保存到应用数据目录 `translations/<translation_id>/mono.pdf` 与 `dual.pdf`，不注册成作者原文，不进入现有证据检索。
- 缓存绑定论文、修订、PDF 哈希、引擎协议、语言、模型端点及参数。打开时再次检查受管路径、文件哈希和 PDF 格式。
- 取消或退出撤销代理，阻断新请求并尽力中断本机在途连接；已送达供应商的请求仍可能计费。外部服务没有停止子进程 API，必须保留外部状态未知提示，不能声称已终止外部排版。
- 重启将未完成翻译标为中断，不自动续发。失败需用户回到翻译板块重新预检及授权，不能使用通用本地任务重试。

## 验收边界

自动化使用匿名 PDF、合成外部服务和合成 Provider；不读取真实 Key、私人 PDF、Zotero 正式库或正式数据库。模拟通过只能证明协议适配、预算、账本和生命周期行为，不证明真实 PDF 翻译质量。收到文件后展示“引擎已生成，全文质量尚未验证”，不将其标为科学准确或与原版完全一致。
