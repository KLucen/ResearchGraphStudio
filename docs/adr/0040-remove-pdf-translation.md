# ADR0040：撤下文献翻译，保留 Lite 阅读功能和数据兼容

日期：2026-11-12（Asia/Shanghai）

状态：已采纳；实际测试、安装包和原生启动结果以 [开发进度](../progress.md) 为准。

## 背景

用户在翻译代理错误分类修复后仍遇到 `TRANSLATION_PROVIDER_TRUNCATED`，并明确要求退回没有文献翻译功能的版本。本轮按该决定撤下功能，不继续提高翻译输出上限或重试真实论文。该错误表示响应截断，不能据此断言供应商的具体模型能力、原论文译文质量或某个配置必然有误。

翻译与其他 Lite 增量曾一同提交。直接 reset 或整体 revert 会同时丢失模型配置、导航和阅读布局等独立改进，因此通过定向移除翻译实现完成回退。

## 决策

- 移除文献翻译板块、设置、前端客户端、业务路由、worker、临时模型代理、外部服务启停和随包 adapter；旧翻译任务不执行、不恢复、不重放。
- 移除翻译运行时准备脚本、专项 smoke 和构建/CI/Tauri 安装资源引用；当前安装包不再分发 PDFMathTranslate、BabelDOC 或翻译离线资源。
- 保留 Zotero、本地 PDF 解析、章节/文本索引、PaperCard + LightGraph、图谱交互、章节导读、证据问答、英文关键词辅助、模型连接/Profile、统一用量和任务管理。
- 保留阅读工作区位于页面上方、论文信息位于末尾独立卡片且默认折叠的布局。
- 保留 Alembic head `lite0008` 和既有迁移链、翻译表结构及必要映射，仅用于已存在数据库的兼容；不执行 downgrade、数据库重建或旧数据迁移。

## 数据和调用边界

本次不删除原始 PDF、已有翻译输出文件、历史翻译行、任务快照或用量记录。已有论文、章节、概览、导读、问答和图谱布局保持。撤下业务 API 后，保留的历史翻译文件与记录不提供翻译执行入口；重新安装旧版本前应单独核对数据库与备份兼容，不能靠原地降级处理。

旧翻译任务不能通过通用任务重试再次执行；启动时将仍在排队或运行的翻译任务停止为已取消，并标记功能已移除，已完成、失败等终态记录保持。启动、GET、查看历史和本地解析均不触发翻译模型调用。历史实际 usage 继续保留，供应商未返回的用量或价格仍为 `unknown`，不能因撤下功能改写成零。本轮验证使用合成 Provider 和隔离数据，不读取真实 Key、私人论文或正式 Zotero 数据库。

## 历史与验证

[ADR0036](0036-optional-pdf-translation-bridge.md)、[ADR0037](0037-managed-translation-server.md) 和 [ADR0039](0039-translation-proxy-request-policy.md) 保留为历史，翻译相关决策由本决策覆盖。[ADR0038](0038-bundled-translation-and-reading-layout.md) 的翻译分发/执行部分同样退役，阅读布局继续适用。

需要验证翻译入口及路由不存在、历史任务无法重放、已有 `lite0008` 数据库可正常启动，以及匿名 PDF 的本地解析/索引为零模型调用。具体命令、测试数量、构建、隔离安装和未测项只记录实际结果，见 [开发进度](../progress.md) 与 [开发日志](../../DEVELOPMENT_LOG.md)；此前翻译专项或旧包成绩不作为本次回退验收。
