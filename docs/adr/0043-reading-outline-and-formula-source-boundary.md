# ADR0043：可收起阅读目录与公式来源边界

日期：2026-11-16（Asia/Shanghai）

状态：采纳；实际实现、验证和安装交付以 [progress](../progress.md) 为准。

## 背景

全文精读目录位于正文上方，问答界面还同时显示章节选择框与目录，阅读长文后需返回顶部才能切换位置。用户要求将两个界面的文章目录改为可展开、收起的侧栏，并指示当前阅读位置；同时询问 PDF 公式定位和解析办法。

## 阅读导航决策

复用独立阅读目录布局组件，在正文左侧显示目录；收起时为正文释放空间，并保留可触达的展开入口。桌面目录在阅读范围内随滚动保持可用，目录长列表独立滚动。窄屏不挤压正文双栏，而使用可关闭的目录面板，支持键盘操作和焦点恢复。

全文精读的当前目录项来自本地标题/章节目标及实际阅读滚动位置。点击目录定位正文；重新展开目录时只让当前项进入目录自身的可视范围，不把正文跳回顶部。没有标题时可使用已有章节与正文来源映射，不能为目录编造章节。目录应使用明确的当前项和展开状态语义。

桌面展开/收起改变正文宽度时，记录可见原文的字符锚点（无法取得时回退到块内位置），重排后恢复该来源位置，避免章节中途阅读退回节首。问答原文框有独立滚动时，同时保持外层原文框和框内文字的位置；没有用户滚动的连续切换复用同一来源锚点。浏览器默认滚动锚定不能替代这一保证。

论文问答只加载当前选定章节时，目录当前项表示这个实际选择；不能把界面滚动伪装成切换章节，也不能由滚动改变用户选择的 section/paper/selection 检索范围。章节切换仍遵守已有本地读取、缓存与授权清除逻辑。既有图谱、段落和历史问答导航继续有效。

本轮只更改界面导航，不变更 API、数据库 head、原文、缓存身份、Prompt 或模型请求流程。目录展开/收起、点击、跟随阅读均零模型调用。

## 公式诊断与后续边界

当前 `ingest.py` 从 PDF 提取线性文字块；`pdf_structure.py` 保存字体/字号/行与 Span 坐标，但没有保存完整文字 flags、基线、方向和字符级数学结构。阅读整理还会压平换行，因此普通文本或高亮渲染无法可靠还原分数、上下标和积分上下限。现在已增加保守的独立公式候选分型，候选保留页码、bbox、原文哈希和 revision-bound `formula_id`，但不代表已经恢复二维数学结构。

原 PDF 字节未被这些展示操作改变。已实现受限的原始区域预览：只读登记且同 SHA 的来源，以页码和 bbox 截取局部图像，并通过 JSON base64 预览接口传给桌面端；不接受任意客户端路径，不修改 Zotero/PDF。疑似公式检测结合字符位置、数学字体/符号、居中布局和编号等线索，不能仅据一个等号或数字决定。行内公式保留在原段，不确定时标疑似。

需要可复制公式时，再按需增加局部公式 OCR → LaTeX，作为独立派生成果，绑定源 SHA、区域、识别器版本和配置缓存，保留原图对照与待核对状态。数学渲染成功不代表识别或科学含义正确，不覆盖旧 Span，也不让通用语言模型猜补缺失符号。模型权重、运行环境、许可和安装包体积需另行评估。

**本轮增量已实现保守公式候选定位、revision-bound `formula_id`、同 SHA 原图预览、可选本地 Pix2Text MFR 识别接口、版本化识别缓存和精读投影自动刷新。** 默认安装包不下载识别权重、不引入重型解析依赖；没有显式配置本地 OCR 时保持 `latex_unavailable`，不伪造 LaTeX。KaTeX 仅渲染通过语法检查且明确标记为 `recognized` 的结果，不能把线性 PDF 文本自动当作正确公式。实际 OCR 结构准确性仍需在用户配置权重后单独验收。
