# ADR 0032：Lite 干净工程与联合论文概览

- 日期：2026-11-09
- 状态：已实现，合并前本地验证中
- 适用范围：ResearchGraph Lite 活跃工程

## 决策

Lite 活跃工程只保留本地阅读所需基础：Tauri 2、React/TypeScript、FastAPI、SQLite/FTS5、Zotero 连接、PDF/章节解析、文本索引、Provider 配置、用量统计和任务管理。完整知识图谱抽取、跨论文推理、Query、Lint、Wiki、旧 Reading/Reasoning 业务、旧迁移和对应测试从活跃目录移除；完整旧工程通过 `backup/pre-lite-refactor` 提供回退点，不把旧应用数据复制到 Lite 数据库。

新数据库从 `lite0001` 空基线初始化。发现旧数据库结构时停止并提示使用新的 Lite 数据目录，避免把旧图谱、任务记录、缓存或原始响应误当成 Lite 数据。选择论文、PDF 解析、章节识别和 FTS5 建索引全部本地执行，默认 0 次模型调用。

B 模块的论文概览由 PaperCard 和 LightGraph 组成。用户显式允许后，两者通过一次联合模型调用生成；输出只包含双语节点名称、简短属性、关系类型和 `EXPLICIT/INFERRED` 基础，不生成 Evidence 节点、段落证据或页码。程序负责 Schema 校验、稳定节点/边 ID、缓存身份、逐尝试 Token 记录和布局持久化。缓存命中不产生新调用；失败不自动重试。

## 取舍

- 保留 React Flow/ForceGraph、布局和图例组件，避免为轻量图谱重新建设画布。
- 把布局和相机与语义结果分开保存；同一论文和文献版本重新生成概览时按稳定节点 ID继承仍存在的布局，换论文或文献版本不串用布局。
- 旧文档、旧安装包、构建输出、运行数据库、日志和实验响应不进入活跃源码或提交；必要规范和基线文档保留。
- `unknown` 只表示信息/计量缺口，不能用来推断实验条件、矛盾或费用为零。

## 验收边界

清理验收必须覆盖：空 Lite 数据库、项目创建、Zotero/匿名适配器、PDF/章节/FTS5、应用重启和 0 次模型调用。P1 另需覆盖联合概览 Schema、单次模型请求、失败记录、缓存命中、显式重生成、跨版本布局隔离、节点/关系交互和布局重置。真实 Provider 科学质量、真实价格、复杂表格/公式、OCR、跨平台和用户原生安装体验另行验收。
