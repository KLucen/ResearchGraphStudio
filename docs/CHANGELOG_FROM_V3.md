# 设计 v3 → v3.3 变化

当前产品是通用科研论文阅读辅助工具，统一使用“知识图谱”。旧 v3 设计保存在 [archive/v3](archive/v3/README.md)。本版是当前阶段的设计迭代，不等同于 Phase 4、安装版本或数据库升级。

| 方面 | 新规则 |
| --- | --- |
| 用户流程 | 选择论文直接自动生成；移除人工审核、待审队列、接受/驳回环节 |
| 核心选择 | 对论文自身贡献/论证/限制的重要性，质量门槛后再排序/覆盖检查；无需领域配置 |
| 持久化 | 原文/表格材料/定位/原输出保留；候选、单元、选择共用 KnowledgeStore |
| 默认图谱 | Paper→核心 Claim→支撑；不为所有可见节点补 Paper 连线 |
| 单元 | 多对多共享成员，导航与科学关系区分，按需展开 |
| Schema | 显式候选 union、质量/选择/版本分离、原语言和可空中文，历史审核仅兼容 |
| Prompt | P01–P11 重新约束，新增 P12 论文整合/P13 核心选择；运行模板暂未替换 |
| Query/Wiki | 未选候选仍可检索，逐段版本依赖与证据；功能仍待后续 Phase |
| 施工 | R0 规范→R1 存储适配→R2 抽取→R3 整合选择→R4 分层视图→R5 验收 |

旧事实与验收报告不反向改写。当前运行 Schema 0009、unified-v3.1 与 P02 3.2；真实响应超时仍为未解决问题。
