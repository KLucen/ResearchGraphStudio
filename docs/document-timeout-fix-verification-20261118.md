# 文档超时修复与页面图片输入验证

日期：2026-11-18（Asia/Shanghai）。需求与边界见 [ADR0051](adr/0051-document-timeouts-and-visual-pdf-input.md)，原始故障见[调查报告](document-timeout-investigation-20261118.md)。

## 实施结果

- 文档等待/总时限独立于文字任务，默认600/1800秒，模型设置可编辑并校验。新文档任务为旧profile补当前默认，不修改原profile或旧任务快照。
- 新增显式页面图片传输：PyMuPDF仅渲染144dpi彩色页面，按原序发送 `image_url` 与原始页号，不抽本地正文/公式/表格，不混发直接PDF字段；旧 `chat_file` 保留。
- 火山/腾讯精确套餐地址提供用户主动的推荐配置按钮。需要视觉模型，并不因此宣称供应商支持或真实质量已通过。推理none需端点支持，用户可保留或另设强度。
- 超时诊断区分连接、上传、等待响应、读取结果和总时限；真实阶段、用时、页面准备数及阈值显示于任务和论文页。页面准备不是模型解析进度，没有伪造百分比。
- `Job.result.document_request` 白名单保存数值、时间和已知枚举，不持久化正文、Base64、密钥或本地路径。失败保留真实开始和模型身份；模型截断不发布成功。
- 取消检查覆盖页间、客户端准备及真实发送前，终态不被进度覆盖；不自动重发、降级或截页。总时限覆盖文件准备、渲染和网络，单页原生渲染不能中途打断，但页像素有界，结束后继续终验。

没有新增迁移，head仍 `lite0012`，旧论文、笔记、源文件和解析历史不重写。

## 输入和验证边界

软件输入上限：PDF50MiB、128页、单页800万/总1.28亿像素、累计JPEG32MiB，超限整份拒绝发送。这些是软件本次资源上限，并非供应商承诺。当前一次发送全部页，未实现分页收费批次、跨批合并或断点恢复；大文件仍可能因服务商图片数量/请求大小/上下文或等待限制失败。

视觉检查使用匿名2页PDF，包含文字、公式、表格与彩色图形。实际图片路线渲染的两页图已目检：文字/表格/图形清晰、无裁切，原页序保持。预览在 `.local/verify/document-timeout-fix-20261118/visual/`，不作为真实模型识别成绩。

专项离线验证涵盖四类HTTP超时、总时限、渲染阶段超时、图片页序与输入字段、读取/响应上限、渲染容量拒绝、加密/损坏PDF、取消前零发送、发送后不发布、旧快照保留、新快照默认和诊断脱敏。新传输专项25项通过，与既有文档/流式专项合计75项通过；worker诊断专项10项通过。

首次真实进程开发烟测发现公开 `JobView.stage` 未加入5个新阶段，轮询会500；已补齐并重新生成契约，新增5项API读取回归。修复后worker专项合计15项通过，开发sidecar端到端成功：本地导入后显式模型重新解析，仅向本机模拟服务发送1次两页图像请求，像素核对页序、无文件字段/绝对路径，三类材料和安全诊断保存读回。首个安装构建因此废弃，失败烟测和首次构建证据保留，最终包必须为契约修复后重建。

## 使用步骤

1. 安装本轮包后，进入“设置与诊断 → 模型 → 编辑提供商”。
2. 对用于解析的视觉模型，点“应用推荐解析配置”，或手动选择“PDF 页面转图片”、等待600秒/总1800秒及端点支持的推理强度。可以新建专用模型配置，避免影响概览/问答的推理设置。
3. 保存并在“论文解析模型”选中该配置。
4. 打开已有论文，使用“使用模型重新解析”并确认本次联网授权。旧任务“重试模型解析”仍沿用旧90秒/文件格式快照。
5. 在任务或论文页查看实际阶段和等待上限。失败时保留阶段与阈值，按显示原因处理，不反复自动重发。

本轮实现验证没有访问正式用户数据库、私人论文、Zotero正式库或密钥，没有真实供应商模型调用；前一轮调查对正式库任务元数据的只读访问另记，不混为本轮验收。供应商真实兼容、真实论文公式/表格质量、用户原生GUI和干净机兼容仍待验证。
