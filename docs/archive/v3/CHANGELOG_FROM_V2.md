# v2 → v3迁移摘要

- 从“审阅优先”改为“**自动建图优先，人工纠错可选**”；程序证据校验不取消。
- 沿用v2完整领域Schema，但新增`GraphProjection`双层模型及独立布局状态。
- 默认只渲染Paper/Concept/Method/Claim/ResearchQuestion五类节点；研究条件和结果进入详情面板。
- 以P02统一章节级多类型抽取为主，P03实体融合和P04翻译修复可异步运行；降低LLM串行调用。
- 允许成功批次增量入图，支持超时后的持久化断点续跑；保留旧多阶段抽取作为评测基线。
- Zotero是PDF来源和阅读入口；不默认复制原文，不把PDF解析块当首页内容。
- 中文短标签优先，英文原文、完整翻译、证据不丢失。
- P3已存在的条件化推理与候选RelationAssertion继续使用；AI候选边与已确认边区别展示，NO_DECISION不生边。
- P4/P5 Query/Lint/Wiki依赖完整版领域图谱，不以简化视图Schema替代数据库。

## 迁移顺序

审计现有仓库与备份 → 旧领域对象映射 → 新GraphProjection服务 → 自动提交/可见状态 → UI力导向与详情 → P02统一抽取 → 分批恢复/双语补齐 → P3关系视觉整合 → 全回归与真实模型验证。

**不要覆盖现有数据库、重做Phase 0或删除已有证据/审核历史。**
