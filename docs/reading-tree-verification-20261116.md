# 缺章修复与三级目录树验证 · 2026-11-16

## 范围与诊断

用户截图中缺少第二、三、四章，且第五章出现重复。只读核对截图对应的原始 PDF 与本地解析，确认是标题漏检、退化表格误吞正文及印刷目录误识别，PDF 本身未缺页。非粗体的小型大写标题使用混合字号，旧门槛漏识别自定义章节；两个退化表格网格误覆盖文字；印刷目录中的题名和页码被作为章节。

这轮只修复本地章节识别、版本化刷新、当前章节关联和目录树。保留已有 Lite 阅读功能，不增加真实模型调用；公式识别仍按 [现有评估](formula-parsing-assessment.md) 另行处理。

## 实现

- `pdf_structure.py`：`structure-v2`、小型大写/编号/书签标题、同基线编号组合、同块多个标题的精确候选；印刷目录材料和退化表格拒收。
- `document_structure.py`、`local_index.py` 和阅读/导读/问答服务：当前树与历史树分开，当前 Section 映射到保留的原始 Span；FTS 按块去重，混合小节使用完整块上下文说明，混合 References 块不进入新章节请求。
- `reading_projection.py/contracts.py`：`reading-document-2`；显式刷新同 SHA 来源并逐块校验，增量保存新解析/章节，按精确字符范围区分标题、正文和参考材料。
- `ReadingOutline.tsx` 和精读/问答：一级至三级嵌套目录，分支独立折叠，定位当前章节展开祖先，目录刷新清除失效选择，晚到问答/关键词响应保持原请求范围。
- API/TS 契约、自动化夹具与安装 smoke 同步。数据库仍为 `lite0010`，无新迁移。

详细边界见 [ADR0044](adr/0044-versioned-pdf-chapter-tree.md)。

## 使用与剩余边界

安装后打开已有论文 → 论文精读 → 全文精读 → **重新整理本地阅读版面**。该操作重新读取本地同 SHA PDF，更新目录和阅读整理，不产生模型请求。新导入论文直接使用新版解析。点击标题前的箭头收起/展开子级，点击标题跳转阅读，定位按钮展开当前章节祖先。

原始 PDF、旧段落/Span、旧模型结果和状态保留。旧全文笔记可能因版面版本变化显示过期，用户可核对后决定是否明确重新生成；本轮不自动收费。旧章节个人状态不自动映射为新章节状态。同块含多个小节时，章节任务使用完整块并注明范围较宽；复杂版面、特殊字体与扫描页仍可能需要人工核对。本轮未实现公式检测、局部原图或 OCR。
