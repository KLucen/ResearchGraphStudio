# 合成参考样例

所有内容均为虚构结构样例，不对应真实论文或实测效果。index.json 映射每个样例到参考契约。

extraction_request/batch、integration_request/proposal、selection_request/proposal、graph_selection、graph_projection/expanded 展示同一条自动构建链。图中共享 Method 只保留一个 ID，background-a 保留但不入主图；Query 可以检索它。另有方法、理论、综述样例，不强造实验。没有人工审核步骤。
