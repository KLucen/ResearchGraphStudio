日期：2026-11-21（Asia/Shanghai）。决策见 [ADR0065](adr/0065-evidence-grounded-paper-card-sets.md)。

## 验证重点

- 合同逐条核对引文、来源、重现次数、类别归属、总览引用和保存内容；拒绝 JSON 重复键/非有限数/未知字段、伪造位置和来源、篡改正文或译文。复杂版面不猜偏移，缺页不造页码。
- 本地与模型路径分别验证成功、缓存、显式授权、重复提交、失败 raw/用量保留、取消、重启、发送前后来源漂移与发布前终验；旧冻结计划不升级。
- 新旧读取/收藏/布局边界、精读关键概念跳转、旧个人理解历史与来源变化后状态读取；知识库来源图谱与联系报告保持独立。
- React/Edge 验证总览和介绍、分类、搜索、原文和辅助译文、真实定位、收藏/已读/隐藏/备注持久、窄屏，以及浏览过程模型生成/布局请求为零。
