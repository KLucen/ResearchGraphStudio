## 公式问题与未完成范围

当前读取普通文字块并压平空白，未恢复分子/分母、上下标、矩阵与积分上下限的二维关系；单纯更换字体或加入数学渲染器无法恢复缺失结构。已有页码、块坐标及来源 SHA 可作为后续受控定位基础，但不能宣称已精准识别行内公式。

推荐先建设同 SHA 原 PDF 的局部原图预览，保留上下文和来源，零 API Token；需要可复制公式时再按需对原图 OCR → LaTeX。识别结果独立缓存、保留原图对照与不确定状态，不覆盖原 Span。OCR 引擎、权重、许可、CPU/GPU 与安装体积还需评估。**这些公式能力不包含在本轮安装包中。**

用户原生 GUI、真实论文的译文/批注质量与实际 Token 成本、正式 Zotero 环境和干净机结果仍需后续验收。完成本轮后不提前开发其他阶段或自动追加付费调用。
