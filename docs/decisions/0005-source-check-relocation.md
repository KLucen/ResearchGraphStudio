# ADR 0005：来源检查与内容一致的重新定位

日期：2026-10-30（Asia/Shanghai）。状态：采用，属于 Phase 1 RG-006 增量。

来源是否可读取与证据有效性分开。用户显式点击“检查文件”后，任务分别检查登记的原路径与已有托管副本，对照该来源所绑定的附件哈希。结果区分内容一致、内容变化、丢失、无法读取、超限及检查过程中变化，并保存检查时间；这不是持续监视、文件锁或知识审核结论。

- 迁移 0003 给 PaperSource 增加 generation 与 last_check；旧记录从 generation=0、尚未检查开始，升级前继续备份。来源检查只更新观察结果，不改变 Paper、AttachmentRevision、Chunk 或既有结论。
- 检查/重定位复用持久化 Job 和有界子进程；每个文件最多读取 50 MiB，整项任务 120 秒，支持取消、退出终止和手动重试。文件读取期间检测到大小、修改时间或文件身份变化，返回 unstable；检测无法阻止检查后的外部修改。
- 重新定位通过原生选择器授权新路径，普通前端请求桥不接受路径。仅哈希与来源当前绑定修订一致且路径不冲突时更新来源路径；保留来源 ID、附件修订和历史文本。托管副本不被此操作重写。内容不同应通过导入流程保存文献/修订，不能伪装为路径修复。
- 请求携带 expected_generation；入队时保存来源代次与哈希，发布时再次核对代次。重新导入或重新定位都会推进代次并清除过期观察（定位成功则保存新观察）。排队期间来源更新时，旧结果失败且不应用；重复请求按幂等键返回原任务。
- 来源修改/观察、SOURCE_RELOCATED / SOURCE_CHECKED 事件和任务成功状态同一事务提交。事件保留重新定位前后路径；事件属于文件溯源，不替代科研 Review。
- 查看历史修订时，界面提示当前来源若已指向其他修订；“内容一致”只对应该来源绑定的修订。项目任务按项目查询，当前仍只返回最近 50 项并显示最近 10 项，完整分页历史后续补齐。

本轮不执行自动重导入、自动知识失效传播或私人目录扫描。缓存回收、持续进度与 RG-007 多片段证据/高亮/校正仍按开发计划继续实施。
