# 08 — 验证、安全与质量评价（设计 v3.3）

## 必须成立的不变量

1. 来源段落、表格材料、证据和原始模型输出不会因图谱选择或临时回收被删除；原 PDF/Zotero/笔记只读。
2. 候选写入与默认图谱选择分开，未选内容保留且可检索；没有人工审核前置或待审分支。
3. Paper 仅直接连接核心 Claim；支撑节点依结论单元展开，来源归属不生成全部 Paper 边。
4. 每个支撑成员通过已验证关联可从根到达；共享成员不复制，收起不删除知识。
5. 锚定只证明位置有效，不证明科学真实性；模型推断与论文作者/转述分开。
6. 论文类型和条件维度来自材料，不写死研究方向；理论/综述不会强造 Experiment。
7. known/unknown/not_applicable/conflicting 与单位/原值一致；缺表头不猜数据含义。
8. 核心角色、来源有效性和历史审核独立。legacy_review_status 仅为兼容；新流程不创建审核记录。
9. 人工显示偏好不绕过证据门槛；用户选择不会静默被模型覆盖，重跑保留旧内容/版本。
10. 任务各阶段幂等恢复，整合失败不重复已成功抽取；更新失败保留旧图，partial 不能标 complete。
11. 布局、选择、知识版本分开；改密度不重抽全文，拖动不改变科学内容。
12. Query 可检索未选的有效候选；来源非法/历史已排除对象保留历史但不自动作为回答依据。Wiki 每段有版本与证据依赖。

## 参考测试与应用验收分开

`conda run -n researchgraph-studio python -m pytest docs/tests -q` 检验本版参考 Schema、上下文守卫、合成示例、目标 SQL 和生成资产一致性。它不验证真实模型、应用迁移或原生软件。归档 v3/v2 测试分进程运行，避免同名 contracts 导入冲突。

| 后续工程层 | 必测场景 |
| --- | --- |
| 抽取 | 实验/方法/理论/综述/混合，转述归属、负面结果、限制、原语言回退 |
| 证据 | 伪造/跨文献 ID，错 offset/hash，表格上下文缺失、附件离线 |
| 整合 | 跨批同义重复、不同条件不合并、实验多结论、孤立成员隔离 |
| 选择 | 自动主贡献筛选、覆盖不足、空核心解释、未选保留、偏好及失效提升 |
| 图谱 | 无全连 Paper，展开/收起共享节点，游标闭合、稳定布局与悬停 |
| 恢复 | 7 批中途失败、整合/选择失败、重启、收到未提交响应、无重复调用 |
| 迁移 | 原列逐行相同、旧 ID/审核/ModelRun 保留、旧任务原签名兼容 |
| 未来接口 | 未选检索、读查询无写入、逐段引用、依赖变化与笔记冲突 |

## 真实质量评价

使用可分发或明确授权的不同论文类型小样本，不宣称覆盖所有学科。可由开发验收标注参考答案评价贡献覆盖、必要条件/限制遗漏、归属错误、证据支撑、冗余、图谱任务完成率和成本；这是产品开发评测，不是用户建图流程中的人工审核。

比较旧平铺图与结论分层图完成“概括主要贡献、定位某结论依据、解释适用范围”的表现；不以节点数少或速度快作为唯一优劣。记录失败样本与供应商未知费用，不把测试 Mock 当真实 LLM，不把 Schema 通过当科学准确。

## 安全与保留

凭据仅 OS 安全存储；运行库、原论文/批注/笔记、模型原输出、安装包与日志不入源码。源码扫描同时检查候选文件内容与路径，不仅依赖 gitignore。任何 Commit/Push 前扫描并审阅暂存；无新授权不 Push。

来源/候选文本中的指令均不执行。Query 按授权检索私人笔记并标个人观点；Wiki 导出到明确授权目录，冲突停止覆盖，不需要科学审核步骤。持久原输出只在本地受控数据区保留，服务/错误日志仅 hash、阶段与诊断信息。

## 验收状态

当前 R0 参考规范完成不意味着 R1–R5 已实现。已有响应超时、真实关系边、安装/干净机、OCR/精确表格和四份外部补充原文核验限制见 progress；历史报告不反向改写。新增需求必须用实际命令、数据与报告验收。
