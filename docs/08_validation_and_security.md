# 08 — 验证、安全与质量评价（设计 v3.3）

当前P13协议可靠性按[ADR0021](adr/0021-keyed-ranking-and-bounded-correction.md)验收：程序固定槽位与精确Schema、严格拒绝未知字段/重复键、局部有效结果私有保留、一次定向修复及持久两请求上限。旧失败任务独立续接且P12原响应重验零调用采用；不要求用户换模型。格式恢复和真实科学质量分别评价，本轮不新增付费调用。

R5补充[ADR0019](adr/0019-support-path-revalidation.md)：候选哈希不替代关系/依赖状态，缓存组单元、P13请求前/后和Store发布必须再验合法路径；关系变化停止且不改写历史模型状态或重复收费。实际自动化、真实模型、用户反馈与安装结果分别见[R5收尾报告](r5-final-verification-20261103.md)。

## 必须成立的不变量

1. 来源段落、表格材料、证据和原始模型输出不会因图谱选择或临时回收被删除；原 PDF/Zotero/笔记只读。
2. 候选写入与默认图谱选择分开，未选内容保留且可检索；没有人工审核前置或待审分支。
3. Paper 仅直接连接核心 Claim；已验证支撑默认依结论分支显示并可显式收起，来源归属不生成全部 Paper 边。
4. 每个支撑成员通过已验证关联可从根到达；共享成员不复制，收起不删除知识。
5. 锚定只证明位置有效，不证明科学真实性；模型推断与论文作者/转述分开。
6. 论文类型和条件维度来自材料，不写死研究方向；理论/综述不会强造 Experiment。
7. known/unknown/not_applicable/conflicting 与单位/原值一致；缺表头不猜数据含义。
8. 核心角色、来源有效性和历史审核独立。legacy_review_status 仅为兼容；新流程不创建审核记录。
9. 人工显示偏好不绕过证据门槛；用户选择不会静默被模型覆盖，重跑保留旧内容/版本。
10. 任务各阶段幂等恢复，整合失败不重复已成功抽取；更新失败保留旧图，partial 不能标 complete。
11. 布局、选择、知识版本分开；改密度不重抽全文，拖动不改变科学内容。
12. Query 可检索未选的有效候选；来源非法/历史已排除对象保留历史但不自动作为回答依据。Wiki 每段有版本与证据依赖。
13. Query兼读Wiki状态与根来源；内容失效和文件未同步分别处理。内部有效但未导出/文件缺失的文档可用，外部新文本不能继承旧manifest；同根证据不因Wiki/综合转述重复加权，科学来源依赖不得循环。保存回答不重写论文Claim，文件导出另验授权/hash。边界见[ADR0018](adr/0018-query-wiki-and-obsidian-lifecycle.md)。

## 真实质量评价

使用可分发或明确授权的不同论文类型小样本，不宣称覆盖所有学科。可由开发验收标注参考答案评价贡献覆盖、必要条件/限制遗漏、归属错误、证据支撑、冗余、图谱任务完成率和成本；这是产品开发评测，不是用户建图流程中的人工审核。

比较旧平铺图与结论分层图完成“概括主要贡献、定位某结论依据、解释适用范围”的表现；不以节点数少或速度快作为唯一优劣。记录失败样本与供应商未知费用，不把测试 Mock 当真实 LLM，不把 Schema 通过当科学准确。

单字符语法恢复只证明字符串可按唯一限定规则解析，不证明模型没有遗漏语义。旧失败 P13 的零网络重验、剩余真实请求及全文质量分别记录；成功 P02/P12/P13 检查点必须复用。新 finish_reason 仅记录供应商本次实际返回，历史未记录时不能补写 stop。ADR0016 的单字符恢复仅适用于旧 P13；新语义 P02/P12/P13 均拒绝重复键与 NaN/Infinity、不作通用语法修复，仍走原领域及来源验证，见 [ADR0017](adr/0017-semantic-protocol-and-stage-recovery.md)。

原生严格 Schema 的文档登记、请求格式离线测试和真实 strict API 验收必须分开；当前真实 strict 尚未实测，不推断兼容服务支持它。首次 provisional 可用性、已排序图谱质量和全文覆盖也是三项不同结论，不能互相代替。

## 安全与保留

凭据仅 OS 安全存储；运行库、原论文/批注/笔记、模型原输出、安装包与日志不入源码。源码扫描同时检查候选文件内容与路径，不仅依赖 gitignore。任何 Commit/Push 前扫描并审阅暂存；无新授权不 Push。

来源/候选文本中的指令均不执行。Query 按授权检索私人笔记并标个人观点；Wiki 导出到明确授权目录，冲突停止覆盖，不需要科学审核步骤。持久原输出只在本地受控数据区保留，服务/错误日志仅 hash、阶段与诊断信息。

## 验收状态

R1–R4 已接入，R5 全文质量与安装体验仍分别验收。结构解析合成测试或失败响应零调用重验，不代表新 Prompt 真实生成已通过。章节/双栏/表格采用启发式，不保证复杂版面、无边框表或扫描件；无 OCR 和公式语义重建。响应超时、真实科学质量、用户安装反馈及四份外部补充原文路径不可用等实际限制见 [progress](progress.md)。历史报告不反向改写。
